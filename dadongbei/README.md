# 大东北我的家乡 · 迪士尼风格交响乐 + 四声部合唱

原曲：刘旗 词曲，何玉 演唱。原谱 1=F，4/4，♩=128，「热爱地」。
编配保留原调 **F 大调**；最后一遍副歌和尾声**升全音到 G 大调**（迪士尼式的“燃点”）。
编制：管弦乐队（全部按 Dreamtonics **Instrument X** 首发的 13 件乐器写）+ 传统 **SATB 四声部合唱**。另有竖琴、钟琴、定音鼓三轨可选，用来加迪士尼的“闪光”。Instrument X 没有这三件乐器，需要另找音源，不用它们也是完整的编配。
长度 78 小节，约 2 分 38 秒。

## 结构

| 段落 | 小节 | 速度 | 内容 |
|---|---|---|---|
| 序 Prologue | 1–4 | Maestoso ♩=72 | 圆号独奏副歌的钩子「大东北 是我的家乡」，竖琴琶音、小提琴高音震音铺底，长笛和钟琴点缀。第 3 小节合唱「啊」进来，渐强到 A7 延长 |
| A 前奏 | 5–13 | Allegro giocoso ♩=128 | 原谱的器乐前奏。双簧管奏旋律，长笛高八度叠上，弦乐拨弦“嘭–恰”，单簧管分解和弦，《美女与野兽》开场那种小镇热闹。第 9 小节起第一小提琴拉弓接旋律，圆号、竖琴进来 |
| B 主歌 | 14–21 | | 女声齐唱「风吹麦浪」，第 18 小节分成两个声部。乐队仍是拨弦，长笛、双簧管（唢呐味的倚音）、单簧管在长音处轮流“接话” |
| | 22–25 | | 男声二重唱「蓝蓝的天上」（男高音唱旋律，男低音低三度），女声在上方哼「啊」。弦乐改拉弓，竖琴在「潺潺流淌」处换成十六分音符的水波，钟琴闪一下 |
| | 26–30 | | 四部合唱「东北人爱吃那酸菜血肠」，全乐队逐步加入。「喜洋洋」长音上定音鼓滚奏，小号上行琶音，第一小提琴上行音阶冲进副歌 |
| C 副歌 I | 31–47 | | SATB 主调合唱。前半段第一小提琴和长笛奏对位旋律；后半段（第 39 小节起）短笛、长笛、第一小提琴高八度叠旋律，两支圆号齐奏第二条对位旋律，大提琴八度跳进推动 |
| D 间奏 | 48–55 | | 原谱前奏旋律交给小号、双簧管和圆号齐奏，像迪士尼进行曲；小提琴、长笛十六分音符旋转。第 52 小节旋律回到弦乐和长笛高八度，第 54 小节合唱「啊」渐强 |
| 转调 | 56–57 | | Am7 → B7sus4 → B7。**第 57 小节第 4 拍全体停住（G.P.）**，只剩竖琴刮奏和短笛、长笛的上行跑句 |
| E 副歌 II | 58–73 | ff | **升到 G 大调**。第一小提琴高八度、第二小提琴原位，两个八度齐奏旋律；两支圆号英雄式对位；小号前半段在长音处加号角，后半段和女高音一起唱旋律 |
| 尾声 Coda | 74–78 | Poco meno mosso → allarg. → Maestoso | 突弱（subito p），只剩合唱、弦乐和竖琴唱「我的家乡」；「贼拉拉的爱你呀」渐强；「我的家～」渐慢，女高音停在高音 A 上延长。最后「乡」全奏：小号和圆号奏「大东北」动机，竖琴刮奏，定音鼓滚奏，结束在 G6/9 和弦 |

原谱是「前奏 → 主歌 → 副歌（反复）→ D.S. 回副歌 → 尾句」。这里唱一遍主歌、两遍副歌（第二遍转 G 调），尾声用原谱最后一行「我的家乡 / 贼拉拉的爱你呀 / 我的家乡」。如果想要原谱那样整首唱两遍，可以把主歌和副歌 I 再接一遍。

## 编配思路

- **调式**：这首歌落在 6（D），是 F 大调的羽调式。和声以 F 大调为主，用 Dm、B♭、C 撑起羽调式的色彩：
  - 主歌：F – Am7 – A7 – Dm（「稻花儿香」的 3–2–7 正好是 A7 的分解和弦），B♭ – Gm7 – C7 – F。
  - 副歌：B♭(add9) – F/A – G11 – Dm，「我的家」唱的 A–C–F 放在不带三音的 G11 上，比 Gm7 更亮。
  - 「哥们相聚」：Dm – Dm/C – G7/B – C，低音半音下行；「醉了月亮」走 Am7 – Dm7 – Gm7 – C9 的五度循环。
  - 主歌进副歌：「喜洋洋」长音上 Gm7 → A7sus4 → B♭，属和弦阻碍进行到 VI，一抬就进副歌。转 G 调前用同样的办法：B7 → C。
  - 结尾：D7 延长在女高音的高音 A 上，然后解决到 **G6/9**。最后的「乡」是 6（E），正好是 G 大和弦的六度音，既回到羽调式的主音，又是大调的明亮收尾。
- **迪士尼的手法**：
  - 序奏圆号独奏 + 竖琴 + 弦乐震音，开出“画卷”。
  - 前奏用拨弦和木管对答，像动画里的小镇清晨。
  - 竖琴刮奏、钟琴点缀，只在关键处用。
  - 副歌小提琴对位旋律“飞”在合唱上方。
  - 转调前一拍全体停住。
  - 最后一遍副歌弦乐八度齐奏旋律，圆号英雄式对位。
  - 结尾渐慢，停在高音延长，再用 6/9 和弦收住。
- **东北味**：双簧管在主歌和副歌的长音处用倚音模仿唢呐（谱上标「唢呐风」），呼应「唢呐吹出了美美的模样」；间奏像秧歌队伍的进行曲。
- **合唱的层次**：主歌先女声齐唱，再女声二部；「蓝蓝的天上」男声领唱、女声哼鸣；「东北人爱吃那」起四部齐唱；副歌是传统的四部主调合唱，每个声部都唱完整歌词，拖腔处写连线。
- **声部检查**（`build.py --check` 自动做）：
  - 各乐器和声部的音域。
  - 所有声部两两之间，八分音符以上的长音不构成小二度或小九度（十六分音符的经过音除外）。
  - 合唱四个声部之间没有平行五度和平行八度，女声齐唱不算。
  - 回读总谱，核对每个音的**实际音高**和数据一致，确保移调乐器没有写错。

## 在西贝柳斯里打开

1. `文件 → 打开`，选 `大东北我的家乡_交响合唱_总谱.musicxml`。
2. 这是**移调总谱**：A 调单簧管（F 大调时有 4 个降号）、F 调圆号、降 B 调小号、短笛、低音提琴、钟琴都按记谱音高写，带移调信息。想看实际音高，打开 `主页 → 乐器 → 移调总谱`（Transposing Score）开关。
3. 另存为 `.sib` 就是西贝柳斯工程。A3 竖版、3.7 毫米谱表；需要重新排版时，全选后执行 `版面 → 格式 → 解锁格式`。
4. 单簧管按 Instrument X 的 **Clarinet in A 1** 写成 A 调单簧管。真人演奏 F 大调一般用降 B 调单簧管，要改的话在西贝柳斯里 `更改乐器` 即可，音高不变。

## 在 Instrument X 里呈现乐队

用到的扩展包：Orchestral Strings（Violin 1 / Viola 1 / Violoncello 1 / Contrabass 1）、Orchestral Woodwinds（Piccolo 1 / Flute 1 / Oboe 1 / Clarinet in A 1 / Bassoon 1）、Orchestral Brass（Horn 1 / Trumpet 1 / Trombone 1 / Tuba 1）。

1. 每条轨导入 `InstrumentX分轨/` 里同编号的文件。MusicXML 是 C 调实际音高，带力度和演奏记号；MIDI 带速度变化和力度曲线（CC1、CC11）。哪个格式导入效果好就用哪个。
2. 两支圆号都用 **Horn 1**，第一小提琴和第二小提琴都用 **Violin 1**。
3. 用 unison 把独奏乐器叠成声部。建议：Violin I 12、Violin II 10、Viola 8、Violoncello 8、Contrabass 6；Horn I、Horn II 各 2（合起来 4 支圆号）；木管、小号、长号、大号保持独奏。
4. 木管、铜管、弦乐每轨都是单音线条（没有双音和分部），不用再拆轨。
5. **需要手动设的演奏法**：
   - 第二小提琴、中提琴、大提琴、低音提琴第 5–21 小节是**拨弦（pizzicato）**，第 22 小节起拉弓。
   - **震音**：第一、第二小提琴第 1–4 小节，小提琴和中提琴第 56–57 小节，第一小提琴第 77–78 小节。第 56 小节长笛有**颤音**。MIDI 里这些都写成长音；如果 Instrument X 没有对应的演奏法，保持长音也行。
   - 其余用智能模式即可。
6. Instrument X 也可以当 VST3 / AU 插件挂在 ACE Studio 里。这样合唱和乐队在同一个工程里，见下一节。

可选的三轨（`非IX_` 开头）：竖琴（上下两行谱合在一轨）、钟琴、定音鼓。用手头任何采样音源都可以。定音鼓前半首调成 F、A、C、D，第 52 小节起改成 G、B、D、E。

## 在 ACE Studio 里呈现合唱

1. 在第 1 小节导入 `大东北我的家乡_交响合唱_全轨.mid`，保留速度信息（序奏 ♩=72，前奏起 ♩=128，第 4、76、78 小节的延长和尾声的渐慢都在速度轨里）。也可以只导入 `合唱分轨/` 里的四个 MIDI。
2. 四条合唱轨（Soprano 女高音 / Alto 女低音 / Tenor 男高音 / Bass 男低音）各加载 Vocal Synth，用 **AI Choir** 把几位同音区的中文歌手合成一个声部（每部 4–8 位）。歌词已经在音符上，拖腔音符是 `-`。歌词乱码就改导 GBK 版。
3. 音区：女高 D4–A5（最高音 A5 只在副歌 II 和尾声的延长上），女低 A3–D5，男高 D3–F♯4，男低 F2–F3，都在舒适区。
4. 乐队轨在 ACE 里挂 Instrument X 插件（或者在别的宿主里渲染好乐队音频再拖进来）。
5. ACE 只渲染能听到的轨。渲染前确认没有轨被静音或独奏。

## 修改后重新生成

```bash
pip install music21 mido
python3 build.py --check   # 只检查：音域、小二度/小九度、合唱平行五八度
python3 build.py           # 生成 output/ 下全部 MusicXML、MIDI、字幕，并回读核对
```

乐谱数据都写在 `build.py` 里：合唱四个声部和几条主要旋律是手写的，每小节一个字符串；和声走向在 `CHART` 里，拨弦、分解和弦、竖琴琶音、长音铺底这些伴奏由生成函数按和声自动写出。改一处，总谱、分谱、MIDI、字幕一起更新。

PDF 预览和试听 mp3 另外渲染（需要 `musescore3 fluidsynth fluid-soundfont-gm ffmpeg`）：

```bash
cd output
QT_QPA_PLATFORM=offscreen mscore3 -o 大东北我的家乡_交响合唱_总谱预览.pdf 大东北我的家乡_交响合唱_总谱.musicxml
QT_QPA_PLATFORM=offscreen mscore3 -o 大东北我的家乡_合唱四声部_预览.pdf 大东北我的家乡_交响合唱_合唱四声部.musicxml
fluidsynth -ni -g 0.5 -F /tmp/dd.wav /usr/share/sounds/sf2/FluidR3_GM.sf2 /tmp/dadongbei_preview.mid
ffmpeg -y -i /tmp/dd.wav -af loudnorm=I=-16:TP=-1.5 -b:a 160k 粗略试听_GM音色_非最终效果.mp3
```

`/tmp/dadongbei_preview.mid` 由 `build.py` 顺带生成：只有力度，没有 CC 曲线，因为 GM 播放时几条轨共用一个通道，CC 会互相打架。
