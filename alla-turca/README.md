# 土耳其进行曲（全曲）· 弦乐四重奏

原曲：莫扎特《A 大调钢琴奏鸣曲》K.331 第三乐章 Rondo alla Turca。改编、制谱：花开当富贵。
按用户给的钢琴谱（虫虫音乐版，4 页）**原调**编配：a 小调 / A 大调，2/4 拍，Allegretto ♩=120。
编制：Violin I / Violin II / Viola / Violoncello（弦乐四重奏，不用钢琴）。风格：古典，照莫扎特、海顿弦乐四重奏的写法。
全曲 223 小节加 1 个弱起小节，约 3 分 44 秒。

## 编配思路

- **声部就是钢琴的声部**：右手旋律给第一小提琴，右手的第二声部（三度、六度）和左手和弦的上音给第二小提琴，左手和弦的下音给中提琴，低音给大提琴。所有音高都来自钢琴谱，`build.py --check` 会逐拍核对：钢琴右手的每个旋律音都有乐器在同一时刻奏出，每个强拍的低音和钢琴一致，没有钢琴谱里没有的和声音（刻意加的几处写在 `ALLOW` 里）。
- **古典的轻**：主题段的伴奏保持在钢琴原来的音区（大提琴 A3 空弦、中提琴 C4、第二小提琴 E4），不往下加厚，和原曲一样轻巧；插部和强奏段大提琴才降低八度。
- **土耳其军乐**：钢琴左手的「倚音琶音 + 八分音符」是模仿土耳其近卫军乐队的大鼓。弦乐上改成大提琴一弓扫过三根弦的琶音和弦（A2–E3–A3）加重音，中提琴同时拉双音。反复时中提琴、大提琴改拨弦，更像鼓。
- **反复不照抄**：古典作曲家常在反复时变换配器（莫扎特自己的弦乐四重奏也这么做）。这里每段第二遍换一种颜色：拨弦、中提琴主奏、两把小提琴齐奏或高八度重复。音符始终是莫扎特的。
- **弓法**：抒情段保留钢琴谱的连线（在弦乐上就是一弓）；强奏的十六分音符改成每拍一弓，分解八度两个音一弓，方便演奏。
- **自动检查**：音域、双音 / 三音和弦能不能按、小二度 / 小九度冲突（钢琴原曲本来就有的不算）、平行五八度（有意的八度齐奏除外），`--check` 必须什么都不输出。

## 转写说明

- 用户给的谱和原典版（DCML 整理的 Henle 版编码）逐小节对照过：每个谱表两个人独立转写（一个对照原典，一个只看图），有分歧的地方放大原图裁定。转写结果在 `source_piano.py`，键是原典版小节号。
- 版本差别：这份谱把原典版的倚音写成了实际的十六分音符（例如开头的 B–A–G♯–A），编配照这份谱写。
- 照这份谱、和原典版不同的两处（请核对）：
  - m52（总谱第 92、108 小节）第 6 个十六分音符，这份谱是 B♯5，原典版是 D6。
  - m55（总谱第 95、111 小节）第 4 个十六分音符，这份谱是 F♯5，原典版是 A5。
- 这份谱里改正的两处印刷错误：
  - m25（总谱第 49、57 小节）左手第三个倚音印成了 D3，按 m26、m29 和原典版改成 E3。
  - m87（总谱第 159、175 小节）左手 G3 漏了升号，按 m23 和原典版改成 G♯3。
- 另外这份谱 m101（总谱第 197 小节）的第二个倚音印成了 E6（其他三个都是 D6），也按原典版用 D6；m64 的反复结束记号漏印，按原典版保留反复。

## 在西贝柳斯里打开

1. `文件 → 打开`，选 `土耳其进行曲_弦乐四重奏.musicxml`（或者直接拖进西贝柳斯）。
2. 各声部带了乐器音色 ID（strings.violin / strings.viola / strings.cello），会自动对应到正确的乐器，拨弦段落也有 pizz. / arco 记号。
3. 打开后 `文件 → 另存为`，就得到 `.sib` 工程。
4. 版面是 11×17 英寸竖版（好莱坞总谱纸），每页 3 行、按乐句换行。想让西贝柳斯自己排，全选后执行 `版面 → 格式 → 解锁格式`，再 `外观 → 重置设计 / 重置位置`。分谱在西贝柳斯里用 `分谱` 面板生成，或者直接用 `土耳其进行曲_分谱.pdf`。

## 在 ACE Studio 里呈现

1. 在第 1 小节导入 `土耳其进行曲_弦乐四重奏.mid`，保留速度信息（♩=120）。MIDI 开头空了一拍，弱起落在第 1 小节第二拍，这样 ACE 的小节线和总谱对齐：**ACE 里的第 N 小节 = 总谱第 N−1 小节**。MIDI 里还有段落标记（A–I）。
2. 四条轨分别加载 AI 乐器 **String Section**（或单独的小提琴、中提琴、大提琴），speaker 分别选 Violins I / Violins II / Violas / Celli。演奏法用智能模式。
3. **拨弦（pizz.）的小节**要在 ACE 里把演奏法改成 Pizzicato（MIDI 里没法可靠地带过去）。下面是 ACE 里的小节号，括号里是总谱小节号：
   - Violin I：74–81、106–108（总谱 73–80、105–107）
   - Violin II：74–81、106–113（总谱 73–80、105–112）
   - Viola：10–16、42–49、58–65、122–129、138–144、170–177（总谱 9–15、41–48、57–64、121–128、137–143、169–176）
   - Violoncello：10–17、42–49、58–65、74–81、106–113、122–129、138–145、170–177（总谱 9–16、41–48、57–64、73–80、105–112、121–128、137–144、169–176）
4. 确认没有轨被静音或独奏，从头播放一遍，让所有轨都渲染。

## 怎么改

```bash
pip install music21 mido pypdf cffi
python3 alla-turca/build.py --check   # 必须什么都不输出
python3 alla-turca/build.py --pdf --mp3   # MusicXML、MIDI、总谱 PDF、分谱 PDF、试听 mp3
```

- 乐谱数据全在 `build.py` 的「THE ARRANGEMENT」一节：每个声部一个 dict，键是原典版小节号，第二遍不同的写在 `VN12 / VN22 / VA2 / VC2` 里；主题再现和第二次进行曲用 `ALIAS` 复用第一次的数据。`FORM` 把它们按演奏顺序展开，把反复处的半小节拼成完整的 2/4 小节。
- token 语法见文件开头：`C5/2` 八分音符（时值以十六分音符为单位，`.5` 是三十二分音符），`A3+E4/2` 双音，`.` 断奏，`>` 重音，`_` 保持音，`tr` 颤音，`arp` 琶音，`( )` 连线，`g:G5` 倚音，`[p]` 力度，`[<] ... [<|]` 渐强线，`{pizz.}` 演奏法文字。
- 换行、换页由 `_systems()` 决定（乐句对齐，39 行 = 13 页 × 3 行）。
