# 情歌（最后一遍副歌）· 人声与弦乐四重奏

原曲：陈没 词，伍冠谚 曲，梁静茹 演唱（电视剧《败犬女王》插曲）。
原谱标的是「(F#) 男调(B♭) 女调(F)」，这里用女调 **F 大调（1=F）**，4/4，♩=70（slow soul，16 beat）。
编制：人声 + Violin I / Violin II / Viola / Violoncello（弦乐四重奏）。
改编、制谱：花开当富贵。
范围：图 3 那一段，也就是最后一遍副歌，从弱起「你写」唱到「天长地久」，只唱一遍。前面加了 4 小节弦乐前奏，后面加了 2 小节尾奏。

> **现行版本以用户 2026-09-28 发回的 MIDI 为准**：弦乐的节奏照用户改过的 MIDI；人声保留用户加的 3 个气口（br），其余节奏按原谱校准。见下面「用户 MIDI 修订」。

## 转写说明

- **八度**：这份简谱把副歌几乎整段写在高音点上，照字面是 F5–C6，女声唱不了。这里按实际演唱的音高放：「给」是 F4，全段最高是「我 / 歌 / 有」的 C5，最低是「可」的 C4。人声音区 C4–C5。
- 「奏 可」的 `1̇.5` 里，5 没有高音点；「是那然」的 `6 1̇1̇` 里，6 也没有。所以「可是」是 C4 → D4，再往上接「那」的 F4。
- 「我……的」：「我」的 A4 用圆滑线拖到下一小节的 G4，「的」唱在第二个 G4 上，再延长到第 2 拍结束。
- 「久」原谱是 `1̇ - 0`，唱 2 拍，这里照谱写。弦乐在第 3 拍接尾奏。

## 编配思路

- **和声简单而高级**：骨架照原谱 `1 5/7 │ 6m 3m │ 4 1/3 │ 2m7 4/5 (5)`，即 F – C/E – Dm – Am – B♭ – F/A – Gm7 – B♭/C（卡农进行），在上面加色彩：
  - `6m 3m` 里的 3m 用 **Am/C**（第一转位），这样低音一路下行：F – E – D – C – B♭ – A – G – C，副歌前后两半都这样走。另一个原因是人声「你和我 / 轻轻的」的 B♭ 正落在这个和弦上，低音如果是 A，会跟人声成小九度。
  - `5/7`（C/E）后半，人声「一 / 首」的 F 提前一个十六分音符进来，低音照用户的 MIDI 留在 E 上到小节末（经过性的小九度）。
  - 6m 写成 Dm7，4 写成 B♭maj7，4/5 写成 B♭maj7/C 色彩。
  - 前奏：B♭maj7 – Am7 │ Gm7 – B♭maj7/C │ B♭maj7 – Am7 │ Gm7 – C7sus4 – C7。
  - 结尾「天长地」：B♭/C 持住，「地」上第一小提琴 F → E（sus4 → 3）转成 C7，再解决到「久」的 F。四个声部都级进解决：E → F、D → C、B♭ → A、C → F。
  - 尾奏借用小四级 **B♭m6**。中提琴 D → D♭ → C 半音下行。第一小提琴把钩子的 `1 7 1 2` 改成 F – E♭ – F – G（落在 B♭m6 上），最后停在 A（3）上，F(add9) 结束。前奏的钩子到这里才真正落地。
- **层层加码（综艺高燃的核心）**：

  | 段落 | 大提琴 | 中提琴 | 第二小提琴 | 第一小提琴 |
  |---|---|---|---|---|
  | 前奏 | 二分音符低音 | 长音 → 八分音符分解 | 长音 → 给钩子配三度 | 钩子 |
  | 副歌前半 | 原谱的 slow soul 低音型 `1 ⌒ 1 5 1`（附点四分 + 两个十六分） | 八分音符波浪（第 8 小节改十六分） | 长音 | 四分、二分音符对位，A5–D6 |
  | 副歌后半 | 八度跳进的八分音符律动 | 十六分音符波浪 | 十六分音符重复音，3+3+2 重音 | 高音区长线 C6–G6，第 12 小节「的——」到 G6 |

- **呼应**：人声前两拍是四分音符（给 / 我、首 / 歌、情 / 歌），第一小提琴这时走动。后两拍人声是十六分音符，弦乐就持长音不抢词。「的——」「久」之后是小提琴的空间。
- **清唱留白**：第 8 小节第 4 拍弦乐全停，只剩人声清唱「还好」，第 9 小节全奏砸进副歌后半。这是原谱鼓手 fill 的位置。
- 各声部都在舒适音区：第一小提琴最高 G6，大提琴最低 C2（空弦），中提琴 C3–G4。
- 脚本会自动检查：每个十六分音符的纵向音程（包括和人声之间）没有小二度或小九度冲突；任意两个声部之间，包括和人声之间，都没有平行五度和平行八度。有意保留、登记在 `build.py` 白名单里的几处：
  - 前奏第 1、3 小节第 4 拍，第一小提琴的 B♭ 对大提琴的 A。这是原曲钩子 `4 → 3` 的倚音，照原曲保留（`CLASH_ALLOW`）。
  - 第 5、9 小节末，人声「一 / 首」提前进来的 F 对低音 E；第 9 小节最后一个十六分，中提琴 F4 对大提琴 E3。都来自用户 MIDI 去掉推拍后的低音（`CLASH_ALLOW`）。
  - 第 5 → 6 小节，第二小提琴 E5 → D5 和大提琴 E3 → D3 八度平行，用户 MIDI 原样（`check()` 的 `allow`）。

## 在西贝柳斯里打开

西贝柳斯的 `.sib` 工程只能在西贝柳斯里存出来，这里给的是 MusicXML，是西贝柳斯官方支持的导入格式。

1. `文件 → 打开`，选 `情歌_副歌_人声弦乐四重奏.musicxml`（或者直接拖进西贝柳斯）。
2. 导入对话框如果有版面相关的选项，选保留文件里的版面。各声部已经带了乐器音色 ID（strings.violin / strings.viola / strings.cello），会自动对应到正确的乐器。
3. 打开后 `文件 → 另存为`，就得到 `.sib` 工程。
4. 版面：A4 竖版，6 毫米谱表。前奏和副歌前半 4 小节一行，副歌后半十六分音符多，2 小节一行。如果想让西贝柳斯自己排，全选后执行 `版面 → 格式 → 解锁格式`，再执行 `外观 → 重置设计 / 重置位置`。

## 在 ACE Studio 里呈现

1. 在第 1 小节导入 `情歌_副歌_人声弦乐四重奏_全轨.mid`，保留速度信息（第 12 小节第 3 拍起渐慢，尾奏继续渐慢）。
2. 人声轨：加载 **Vocal Synth**，选一个中文流行女声（温暖、中低音区好听的唱法更接近原唱）。歌词已经在音符上，拖腔音符标的是 `-`，会连着上一个字唱。如果歌词是乱码，删掉这一轨，改导 `情歌_人声_带歌词_GBK编码备用.mid`。也可以单独把 `情歌_人声_带歌词.mid` 拖进一条人声轨。
3. 四个弦乐轨：都加载 AI 乐器 **String Section**，speaker 分别选 **Violins I / Violins II / Violas / Celli**。演奏法保持默认的智能模式（smart mode）即可，这版没有拨弦，也没有弱音器。
4. 第 8 小节第 4 拍弦乐是故意空着的（人声清唱「还好」），不要补。
5. 人声轨里有 3 个歌词为 `br` 的音符（第 6、7、11 小节），是用户加的气口，ACE 会合成成吸气声，不要删。
6. 弦乐的 AI 渲染在播放时进行，被静音或独奏的轨不会渲染；弦乐听起来是钢琴声，说明那条轨还没加载音源。

## 修改后重新生成

```bash
pip install music21 mido
python3 build.py          # 生成全部文件到 output/
python3 build.py --check  # 只检查音域、声部冲突和平行五八度
```

乐谱数据都写在 `build.py` 里，每小节一行，时值以十六分音符为单位。改一处，MusicXML、MIDI 和字幕会一起更新。
PDF 总谱用 LilyPond 排（读的是同一份 `build.py` 数据），试听 mp3 用 FluidSynth 另外渲染：

