# 甲乙丙丁（副歌）· 人声与弦乐五重奏

原曲：应晓璃 词曲，李佳薇 演唱。1=F，4/4，♩=65。
编制：人声 + Violin I / Violin II / Viola / Violoncello / Contrabass。

## 文件（`output/`）

| 文件 | 用途 |
|---|---|
| `甲乙丙丁_副歌_人声弦乐五重奏.musicxml` | **西贝柳斯总谱**（含歌词、力度、连线、排练号），ACE Studio 也能直接导入 |
| `甲乙丙丁_副歌_人声弦乐五重奏_全轨.mid` | **ACE Studio 用**：人声 + 五个弦乐声部共 6 轨，带速度变化（尾奏渐慢） |
| `甲乙丙丁_人声_带歌词.mid` | 单独的人声 MIDI，带逐字歌词（UTF-8），拖腔音符的歌词为 `-` |
| `甲乙丙丁_人声_素.mid` | 单独的人声 MIDI，不带歌词（素的） |
| `甲乙丙丁_人声_带歌词_GBK编码备用.mid` | 如果导入后歌词是乱码，换用这个 |
| `甲乙丙丁_弦乐五重奏_伴奏.mid` | 只有五个弦乐声部 |
| `甲乙丙丁_副歌_总谱预览.pdf` | MuseScore 排的预览，方便在手机上看；正式排版以西贝柳斯为准 |
| `粗略试听_MuseScore音色_非ACE效果.mp3` | 用普通音源渲染的试听，只用来检查音符，**不是最终音效** |

所有文件都从同一份 MIDI 时间线导出（第 1 小节 = 前奏开头），人声从第 8 小节第 4 拍弱起「你我」进入。
导入 ACE 时每个文件都放在第 1 小节，就能和伴奏对齐。

## 结构

| 段落 | 小节 | 内容 |
|---|---|---|
| 前奏 Intro | 1–8 | 主题先由大提琴在 A 弦上唱出（1–4），再由第一小提琴高两个八度接过（5–8），大提琴在下面以主题的头动机「D-F-A」对答。第 8 小节停在 C9sus4 上，人声弱起进入 |
| 副歌 Chorus | 9–16 | 你我怎么两清……能否换来一点同情 |
| 尾奏 Coda | 16 第 3 拍–21 | 第一小提琴先把「换来一点同情」的尾句高八度回声一次；大提琴回到前奏主题；最后经过 B♭m6（借用和弦）落在 F 大调加九和弦上结束，延长、渐慢 |

## 编配思路

- **流水**：中提琴和第二小提琴交替奏十六分音符。一件乐器奏三个音，第四个音留住，另一件乐器接着往上走，两件乐器连成一条不断的流水线，每件乐器本身都不难拉。前奏和尾奏用这个织体；副歌人声比较密，所以中提琴改成八分音符分解和弦，只在高潮（13–14 小节）回到十六分音符。
- **呼应**：弦乐在人声的长音和气口里应答。「丁」（第 10 小节）时大提琴用主题头动机上行接话，第一小提琴高八度托住；「命」（第 12 小节）时大提琴再答一次，第一、二小提琴用三音的小句六度并行，推进到高潮。
- **高潮**（13–15 小节，「爱情这场酷刑」）：第一小提琴和大提琴相隔两个八度，唱一条级进下行的对位线（D–C–B♭–A–G–F–E–F），第二小提琴在下方用三度、六度陪衬，和人声的上行形成反向进行。
- **和声**：以 IV–V–ii–iii–IV–V–I（4-5-2-3-4-5-1）为骨架，多用大七、九度、挂四和弦。脚本自动检查过每个十六分音符的纵向音程，声部之间没有小二度或小九度的冲突。
- 各声部都在舒适音区，没有炫技段落：第一小提琴最高 E6，低音提琴最低 F1。

## 在西贝柳斯里打开

`文件 → 打开` 选 `.musicxml`（或把文件拖进西贝柳斯）。各声部已经带了 MusicXML 乐器音色 ID（strings.violin 等），导入时会自动对应到正确的乐器。低音提琴按惯例记谱高八度（带移调信息）。导入后建议执行一次 `版面 → 重置设计 / 重置位置` 让西贝柳斯重新排版。

## 在 ACE Studio 里呈现

1. 导入 `甲乙丙丁_副歌_人声弦乐五重奏_全轨.mid`，保留速度信息（尾奏有渐慢）。
2. 人声轨：加载 **Vocal Synth**，选一个中文女声（偏有力度的流行唱腔）。歌词已经在音符上；拖腔音符标的是 `-`，会连着上一个字唱。如果歌词显示乱码，删掉这一轨，改导 `甲乙丙丁_人声_带歌词_GBK编码备用.mid`。
3. 五个弦乐轨：都加载 AI 乐器 **String Section**，speaker 分别选 **Violins I / Violins II / Violas / Celli / Basses**，对应五个声部。演奏法保持默认的智能模式（smart mode）即可，这版编配没有用拨弦或加弱音器。
4. 如果弦乐听起来是钢琴声，说明这条轨还没加载音源。
5. 弦乐的 AI 渲染在播放时进行，被静音或独奏时不会渲染。

## 修改后重新生成

```bash
pip install music21 mido
python3 build.py          # 生成全部文件到 output/
python3 build.py --check  # 只检查音域和声部冲突
```

乐谱数据都写在 `build.py` 里（每小节一行，时值以十六分音符为单位），改一处，所有 MusicXML 和 MIDI 会一起更新。
