# 10 秒样片分镜（歌曲 0:28.0 – 0:38.0）

**一句话**：Clawd 想一直和 TA 牵着手坐在电线上，可一滴雨砸断了牵着的手，TA 转身走了，Clawd 被留在一群陌生人中间。

**世界**：五根电线横过天空，就是五线谱；坐在线上的 Clawd 就是音符。回忆是暖橙色的黄昏，现在是靛蓝色的雨夜。颜色从暖走到冷。

**母题**：牵着的手，像连着两个音符的符杠。它断了以后，TA 的位置被陌生人占满。

**Clawd 的情绪线**：开心 → 心动 → 惊愕 → 难过 → 困惑（找不到 TA）→ 难过（头顶下雨）

**镜头**

```
A  28.00–30.23  [进：从纸面圈入，落在两人身上]  回忆，暖黄昏
   28.00–28.60  两个 Clawd 并排坐在中间那根线上，手臂连在一起（眼睛：画面中央）
   28.62–29.07  「你」：TA 转头看向 Clawd
   29.08–29.54  「我」：Clawd 回头，眼睛变成爱心，冒出小心心
   29.54–30.23  「怎么两清」：一滴亮晶晶的雨从画面顶上直直落下（眼睛跟着它），
                正落在牵着的手上
B  30.23–38.00  [转场：切在动作上，同一构图，从暖切到雨夜，一下闪白]  现在，雨夜
   30.23–30.90  手被砸断，两截手臂弹回，水花溅开；Clawd 吓一跳，TA 面无表情
   30.92–31.60  「怎么忍心」：TA 背过身去（经过背影转向右边）
   31.60–34.70  「怎么做回」：TA 站起来，沿着电线走远，走出画面；
                Clawd 伸手去够，手慢慢垂下，变得难过
   33.23–34.85  「甲 乙 丙 丁」：每唱一个字，从右上方落下一只灰色的陌生 Clawd，
                落在线上时压一下；第四只正好落在 TA 刚走过的位置
   35.08–36.00  「丁」的长音（大提琴接话）：Clawd 左右张望，冒问号，认不出 TA 在哪
   36.00–37.45  「难道非要耗尽」：Clawd 难过，头顶飘来小乌云，镜头慢慢推近
   [出：37.45–38.00 圈出，收在 Clawd 身上]
```

检查：每个镜头都有事件；一次只讲一件事；每个接缝都有转场；画面里没有文字；雨从 A 的一滴变成 B 的一场，前后呼应。

**渲染**：没有显卡的机器上，角色的水彩晕染改为平涂（`lite.js`），背景仍是真水彩，但每个镜头只画一次后重复使用；这样一帧不到 1 秒。
