# Unravel（全曲）· 弦乐四重奏

《东京喰种》OP。作曲、原唱：TK from 凛として時雨。按 **Animenz 的钢琴改编版**（用户给的谱）改编成弦乐四重奏。改编、制谱：花开当富贵。

- 调：g 小调（原谱两个降号，保持原调）。4/4，♩=134，弱起八分音符 + 132 小节，全长约 3 分 57 秒。
- 编制：Violin I / Violin II / Viola / Violoncello，纯器乐（没有人声、没有歌词）。
- 风格：忠实于 Animenz 钢琴版的旋律、和声、结构和力度，改写成弦乐自己的语言：
  - 钢琴的踏板改成真正的长音；
  - 分解和弦交给一位演奏者完整拉；
  - 华彩和崩落段用接力；
  - 高潮用双音、三音和弦和下弓。
- 不加原谱没有的音：脚本会逐个十六分音符和钢琴原谱比对。

| `Unravel_弦乐四重奏.mid` | **弦乐 MIDI**，四轨：Violin I / Violin II / Viola / Violoncello。带力度曲线（CC1/CC11）、重音、断奏长度、颤音、震音、琶音和段落标记，给 ACE Studio 用 |
| `粗略试听_GM音色_非ACE效果.mp3` | 用普通 GM 音源渲染的试听，只用来核对音符，**不是最终音效** |

## 编配要点

- **踏板 → 长音**：钢琴靠踏板撑住低音，弦乐没有踏板，所以低音交给大提琴拉长音（前奏、间奏、桥段），并尽量用空弦（G2、D3、G3）共鸣。
- **一个音型一个人**：分解和弦、十六分音符固定音型都交给一位演奏者完整拉，不在声部之间切碎。只有两处故意接力：华彩（66–73）和崩落（78–81），交接处用同音衔接，听起来是一条线。
- **双音都能拉**：脚本按每件乐器的把位检查双音：
  - 小提琴、中提琴的手指跨度不超过纯四度；
  - 大提琴在琴颈上不超过大三度。
  - 大提琴在低把位按不了的八度双音都改成了单音，或者改成空弦八度、一指五度、滚奏三音和弦。
- **旋律永远在上面**：只在第 43 小节钢琴旋律降到低音区时，中提琴也跟着降下去，不压旋律。
- **力度**：跟随钢琴的力度（pp → p → f → ff），伴奏在弱段比旋律低一级。终副歌 112 小节用 fff，让最后一次副歌成为全曲的顶点。
- **音域**：
  - 第一小提琴最高 D7（华彩的最高音），长时间的高音段用 8va 线；
  - 大提琴最低 D2；
  - 中提琴最高 G5（第 57 小节起用高音谱号）。

## 转写说明（请知悉）

- 钢琴谱逐小节转写了两遍（两个独立的转写，互相看不到对方），两遍完全一致。之后又做了两轮核对：
  - 按重复段落、音程和八度跳进找可疑处；
  - 另一组人逐个音头对照原图找漏音。
- 只找到一处漏音：第 81 小节左手的全音符 D1+D2，已补上。
- 钢琴最低的 G1、E♭1、D1 等大提琴拉不到，一律改高八度（G2 就是大提琴的空弦 G）。
- 钢琴的八音盒段落（第 90–96、129–130 小节）在 8va 下最高到 G7，小提琴拉不到，第一小提琴整体低八度拉，旋律形状不变。
- 转写的钢琴数据只用来检查编配，没有放进公开仓库（Animenz 的钢琴谱有版权）。

## 在西贝柳斯里打开

1. `文件 → 打开`，选 `Unravel_全曲_弦乐四重奏.musicxml`（或者直接拖进西贝柳斯）。
2. 导入对话框如果有版面相关的选项，选保留文件里的版面。各声部已经带了乐器音色 ID（strings.violin / strings.viola / strings.cello）。
3. 打开后 `文件 → 另存为`，就得到 `.sib` 工程。
4. 版面：11×17 英寸竖版，每页 3 行，每个排练号都在行首。想让西贝柳斯自己重排，全选后 `版面 → 格式 → 解锁格式`。

## 在 ACE Studio 里呈现

1. 在第 1 小节导入 `Unravel_弦乐四重奏.mid`（带速度 ♩=134；开头是一个八分音符的弱起）。
2. 四轨分别加载 AI 乐器 **String Section**，speaker 选 Violins I / Violins II / Violas / Celli。如果 ACE 里有独奏小提琴、中提琴、大提琴，用独奏的更接近真正的四重奏。
3. 演奏法保持智能模式。这版**没有拨弦**，也没有弱音器。
4. 第 78–81 小节的震音在 MIDI 里写成了快速重复音。如果 ACE 有 tremolo 演奏法，可以把这几小节改成长音再选 tremolo。
5. 华彩（66–73）和崩落（78–81）是几个声部接力的音阶，渲染后听一下交接处是否连贯，必要时微调每轨的起音时间。
6. 确认没有轨被静音或独奏，从头播放一遍，让所有轨都渲染。

## 修改后重新生成

```bash
pip install music21 mido pypdf cffi
UNRAVEL_PIANO=/path/to/piano_source.json python3 build.py --check   # 必须什么都不输出
python3 build.py --mp3 --pdf     # MusicXML、MIDI、试听 mp3、好莱坞总谱 PDF
```

- 乐谱数据在 `sections/sec01.py … sec15.py`，每段一个文件，每小节一行，时值以六十四分音符为单位（十六分 = 4，八分 = 8，四分 = 16）。语法见 `build.py` 开头。
- `arrangement.py` 把各段合在一起，里面还有排练号、换行、换页。
- 编配规范和各段分工：`ARRANGING.md`、`SECTIONS.md`。
- 版面规划：`layout.py`。
- `--check` 查三类问题：
  - 各乐器音域；
  - 双音能不能按得到；
  - 和钢琴原谱对照：旋律、低音有没有漏，有没有钢琴里没有的音。
  - 第三项需要钢琴转写数据 `piano_source.json`（不在仓库里）；没有它时只查前两项。
- PDF 需要 MuseScore 4 和 Chromium，环境准备见 `.claude/skills/hollywood-score/SKILL.md`。mp3 用 FluidSynth + FluidR3 GM 音色。
