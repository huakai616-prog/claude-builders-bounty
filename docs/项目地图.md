## 旧做法：泪海的 MuseScore 3 预览

泪海的 `泪海_副歌_总谱预览.pdf` 是 MuseScore 3 出的旧版预览（不是好莱坞模板；MuseScore 3 读不了好莱坞样式，好莱坞 PDF 要用 MuseScore 4）。要重出这份旧预览时：

```bash
apt-get install musescore3 fluidsynth fluid-soundfont-gm ffmpeg
cd leihai/output
QT_QPA_PLATFORM=offscreen mscore3 -o 泪海_副歌_总谱预览.pdf 泪海_副歌_人声弦乐四重奏.musicxml
```

- 用 MuseScore 3 看排版：`mscore3 -o page.png …` 按页出 PNG。PNG 是透明底，看之前先铺白底。（好莱坞 PDF 用 `tools/hollywood/qa.py pages`，pdftoppm 出的是白底。）
