## 改旧歌时

- **重出 PDF**：情歌、大东北、泪海、甲乙丙丁、茉莉花的 PDF 或署名还没按好莱坞标准重做。用户要的时候，或这首歌因为别的修改要再交付时（交付标准要好莱坞 PDF），用 `tools/hollywood` 重出（照 `chatang/build.py` 接 `--pdf`），再更新交付中心。
- **改不在 `main` 上的歌**：`git fetch origin '+refs/heads/*:refs/remotes/origin/*'`，从 `main` 开新分支，`git checkout origin/<分支> -- <目录>/` 只拿歌曲目录（别带旧分支的 `AGENTS.md`）；交付后把 `catalog.py` 里它的 `ref` 改成 `None`，`AGENTS.md` 精简表和这里的分支改成 `main`。
- **用户确认了待确认的事，或改了旧歌的结构**：同步改 `catalog.py` 里它的 `questions`、这里那一行、`AGENTS.md` 的精简表、那首歌的 README；结构变了还要改 `docs/ACE-Studio.md` 里它的渲染步骤和编配手法索引（简表和详细版）里它那一段；再重新发布交付中心。
- **泪海只唱一遍**：用户已经按两遍在 ACE 渲染、Logic 混音，《等潮》视频（分支 `claude/elegant-pascal-83rncr` 的 `leihai/video/`）按这版 118.83 秒的混音对的时间；改成一遍要重新渲染、混音，视频也要重排，先跟用户确认。做法：把第 14–24 小节换成直接进尾奏的结尾（见 `leihai/README.md` 末尾）。

## 旧做法：泪海的 MuseScore 3 预览

只在用户点名要这份旧预览时用；再交付泪海时照 `chatang/build.py` 接 `--pdf` 出好莱坞 PDF。

泪海的 `泪海_副歌_总谱预览.pdf` 是 MuseScore 3 出的旧版预览（不是好莱坞模板；MuseScore 3 读不了好莱坞样式，好莱坞 PDF 要用 MuseScore 4）。要重出这份旧预览时：

```bash
apt-get install musescore3 fluidsynth fluid-soundfont-gm ffmpeg
cd leihai/output
QT_QPA_PLATFORM=offscreen mscore3 -o 泪海_副歌_总谱预览.pdf 泪海_副歌_人声弦乐四重奏.musicxml
```

- 用 MuseScore 3 看排版：`mscore3 -o page.png …` 按页出 PNG。PNG 是透明底，看之前先铺白底。（好莱坞 PDF 用 `tools/hollywood/qa.py pages`，pdftoppm 出的是白底。）
- 旧 A4 版（MuseScore 3 预览、LilyPond）的排版经验：A4、6 mm 谱表时，含十六分音符的段落一行放 3 小节。强行放 4 小节，会有一小节被挤到下一行单独一行。换行由 `polish()` 里的 `SYSTEM_BREAKS` 控制。（好莱坞 11×17 的每行放几小节见 SKILL.md「Choosing system breaks」。）
