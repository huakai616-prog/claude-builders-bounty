# 编配手法索引（简表）

动笔构思新歌之前读完这一页，写完再对照一遍：新歌的织体、和声、前奏、高潮、尾奏不要和下面任何一首撞，尤其是第一节里已经用过两次以上的手法。用户否定过「照搬」（我不难过照搬泪海，被评「难听」，原话见 `AGENTS.md`「用户怎么提需求」）。

- 看着撞了：先看 `docs/编配手法索引_详细.md` 里那首歌的一节（详细版里没有的歌跳过这一步）；还拿不准，再读那首歌的 `README.md`「编配思路」（Unravel 叫「编配要点」，另见 `unravel/ARRANGING.md`）。不在 `main` 上的歌用 `git show origin/<分支>:<目录>/README.md` 读（先 `git fetch origin '+refs/heads/*:refs/remotes/origin/*'`），茉莉花没有 README，看 `generate_score.py`。
- 这里还没有的歌（刚交付、没补进来的），直接读它的 README。
- 新歌交付时，照下面的格式在第三节末尾加一段：先一行「范围 · 编制 · 调 · 速度 · 目录（分支）」，再列 标志 / 织体 / 和声 / 前奏 / 推进与高潮 / 尾奏；它用到了第一节里的手法，就把它的名字补进那一条；和第三节某一首撞了、第一节还没有的手法，在第一节新加一条（写两首的歌名和小节）。第三节前十二首不是按时间排的（最后做的是我和我的祖国、Unravel、冬风，都在 2026-09-30 前后），从这以后新歌一律加在末尾，最后一段就是上一首。
- 器乐改编（土耳其进行曲、Unravel、冬风、诀别书）的和声大多照原谱，列在这里是为了别把它们的配器手法搬进别的歌。

## 一、已经用过两次以上的手法

新歌默认不用。真要用，在 README 和回复里写清楚这首歌为什么需要它，而且不要和上一首连着用。

- 尾奏 IV(maj7/maj9/add9)（茶汤是 ii7）→ 借用 iv6（m6）→ I（多为 add9），内声部 6–♭6–5 半音下行（F 调里是 D–D♭–C） — 用了六次：茉莉花（尾声 B♭(add9)→B♭m6→F 三和弦，中提 D–D♭–C）、泪海（中提 D–D♭–C）、甲乙丙丁（一提 D–D♭–C，中提持 D♭）、我不难过（A♭maj9→A♭m6→E♭(add9)，中提 C–C♭–B♭）、情歌（中提 D–D♭–C）、茶汤（Bm7→Dm6→A 三和弦，中提 F♯–F–E）
- 副歌中段长音上放借用 iv（m6）当暗色 — 泪海（12、22 小节「幕」B♭m6）、我不难过（9 小节 A♭m(add9)→A♭m6；17 小节第二次改走 A♭m(add9)→D♭9）；诀别书 18、26 小节 B♭m6/C（18 二提 D♭6，26 中提 D–D♭–C）照原谱，算同色
- 尾奏一提 p/pp「eco」弱奏回声人声钩子、尾句或前奏动机 — 泪海、甲乙丙丁、我不难过、情歌、茶汤；茉莉花尾声 26 一提 p 再奏前奏末句后落 C5 长音（没标 eco）、诀别书 49–52 一提 pp lontano 高八度奏前奏动机 D–A–G–A、Unravel 128–130 一提独奏后八音盒主题最后一次（后两首照原谱），同类
- 终和弦 I(add9)，9 音放在内声部（中提双音或二提） — 泪海、甲乙丙丁、我不难过、情歌（大东北结尾 G6/9 是同一类）
- 前奏低声部长音铺底，一提 dolce 唱钩子，钩子在副歌长音上回声一次，尾奏 eco 再出现 — 泪海（人声钩子）、我不难过（人声钩子）、情歌（原曲弦乐钩子；副歌里没有回声，只在尾奏回来）、茶汤（原曲前奏动机，铺在 C♯4 持续音上）；诀别书（原谱动机 D–A–G–A，pp 长音铺底，12 二提在旋律长音里回应，尾声高八度 pp 回来，照原谱）近似
- 前奏把钩子 / 动机奏两遍，第二遍加厚：二提配三度或两把小提琴八度齐奏，中提同时从长音改八分分解（波浪）进来 — 情歌（m3–4 二提在下方配三度、中提改八分）、茶汤（m6–9 两把小提琴八度齐奏高八度、中提八分波浪进入）；泪海前奏钩子连唱三次、第三次移到 F5，同类
- 前奏停在 V7sus4 / V9sus4（→V7）上，人声弱起（或紧跟着）进入 — 泪海（C7sus4→C7，第 4 拍弱起）、甲乙丙丁（C9sus4 留白，第 4 拍弱起）、我不难过（B♭7sus4，第 4 拍后半弱起）、情歌（C7sus4→C7，第 4 拍弱起）、茶汤（Esus4→E7，人声第 10 小节第一拍后半进）
- 前奏从 IV（maj7/maj9）起，不从主和弦起 — 甲乙丙丁（B♭maj9｜Am7 Dm7｜Gm7 C9sus4）和情歌（B♭maj7–Am7｜Gm7–B♭maj7/C）同调，进行几乎一样，低音 B♭–A–(D)–G–C（甲乙丙丁多一个 Dm7 的 D）；我不难过（A♭maj9）、茶汤（Dmaj9）也从 IV 起；大东北序奏（B♭add9）、诀别书（B♭maj7，原谱）同样从 IV 起
- 下行低音骨架 1–7–6–5–4–3–2–5（卡农式） — 泪海、情歌（同调，同一条 F–E–D–C–B♭–A–G–C）、茶汤（A–G♯–F♯–E–D–C♯–B–E，README 自己写了「同泪海骨架」）
- ♭VI–♭VII–I「燃点」：人声持主音，低音一路上行，同时大提琴八度双音 — 泪海 24 小节（D♭–E♭(add9)–F）、我不难过 20–21 小节（C♭maj7–D♭(add9)–E♭）
- 阻碍进行进副歌 / 进燃点（V 不解决到 I，落到 vi、♭VI 或 IV） — 茉莉花 19（C→Dm）、大东北（「喜洋洋」A7sus4→B♭ 进副歌，转调前 B7→C）、泪海 23→24（C→D♭）、我不难过 19→20（B♭sus4→C♭maj7）（后两首是 ♭VI–♭VII–I 燃点的入口）
- 4–5–3–6（IV–V–iii–vi）当推进进行 — 我不难过（骨架）、茶汤（B 段「燃」点的主要来源）、大东北（「这嘎达土生土长」B♭maj7–Cadd9–Am7–Dm7）、诀别书（前奏和主题，原谱）；甲乙丙丁的 4–5–2–3–4–5–1 是近亲
- 五度循环下行 iii–vi–ii–V(–I)（或从 IV 起 IV–iii–vi–ii–V 绕圈） — 甲乙丙丁（前奏 B♭maj9｜Am7 Dm7｜Gm7 C9sus4）、茶汤（B 段 Dmaj7–E–C♯m7–F♯m7–Bm7–E7sus4，即 4–5–3–6–2–5，后四个一路五度）、大东北（「醉了月亮」Am7–Dm7–Gm7–C9sus4–C9）；我和我的祖国（副歌后半 Gm–Cm7–F7–B♭7–E♭maj7）、诀别书（副歌 Gm7–C7–Fmaj7–B♭maj7–Em7♭5–A7–Dm）、冬风 53–54 都照原谱；我不难过（Gm7 Cm7｜A♭maj9 Fm7｜B♭7sus4）、茉莉花（Am7 Dm7｜B♭ C）是半截 iii–vi
- 副属和弦第一转位做半音低音（X7/三音 → 下一个和弦） — 泪海（Dm7–G9/B–B♭m6，低音 D–B–B♭–A）、大东北（「哥们相聚」Dm–Dm/C–G7/B–C）、我和我的祖国（E♭–G7/B–Cm7、A♭–F/A–B♭，照原谱）
- 中提琴八分分解和弦「波浪」铺底（legato, come onde），推进时加密成十六分 — 泪海、甲乙丙丁（副歌 9–12 八分，13–14 十六分）、我不难过、情歌、茶汤；同一族：茉莉花「如水」八分四音波纹（中提、二提、大提轮流拉）、甲乙丙丁前奏「流水」（中提和二提交替十六分）、大东北副歌中提八分分解、诀别书 9–12、Unravel 前奏 5–15 和尾声 122–127（中提拉钢琴左手 3+3+2 八分分解和弦，照原谱）、土耳其尾声 205–211 中提阿尔贝蒂十六分（照原谱）
- 副歌前半同一套组合：大提二分音符下行低音 + 中提八分波浪 + 二提长音「光环」（常拉大七度）+ 一提休止，只在人声长音处（多为高八度）回声钩子 — 泪海 6–9、我不难过 5–8、茶汤 10–13；甲乙丙丁 9–12（二提长音、一提休止到「丁」高八度托住）、茉莉花 A 段（一提只在 10、14 小节长音处高八度回声）形状相同；情歌 A 段部分相同（中提波浪 + 二提长音）
- 两把小提琴三度 / 六度平行双线 — 泪海 10–13、甲乙丙丁（12 小节六度小句，高潮时二提在下方三度、六度陪衬）、我不难过 9–12、情歌前奏第二遍（二提在下方配三度）、我和我的祖国（5–7 小节一提 + 中提，65–68 啦啦段两把小提琴高八度跟女声六度平行）；茉莉花 B 段三、四度交替，土耳其、诀别书 8（二提在一提下六度）照原谱三、六度，都近似
- 高潮前一小节：两把小提琴平行十六分上行音阶，中提、大提十六分（重复音或八度交替）推属和弦 — 泪海 15（三度）、我不难过 12（三度）、茶汤 17（四度平行五声音阶，下面 A7）；我和我的祖国 32、64（三度，只在后半小节，中提大提持主和弦长音，取自原谱钢琴过门）、大东北 30 小节一提十六分上行冲进副歌，同类
- 高潮前最后一拍弦乐 / 全体停（G.P.），人声清唱，下一拍全奏砸进去 — 泪海 15、我不难过 12、情歌 8（「还好」）、茶汤 17（「僵」）、大东北 57（转调前 G.P.）、诀别书 40（G.P.→41 Grandioso）；我和我的祖国 21–22 的清唱有意放在主歌中段，位置不同
- 「层层加码」分工表：每段每件乐器换更密的节奏型（长音→八分→十六分） — 泪海、我不难过、情歌、茶汤（四首 README 都有同一张表）；诀别书（长音→八分→十六分 bariolage）同类
- 第二遍 / B 段大提琴八分音符八度跳进（marcato） — 泪海、我不难过、情歌、茶汤、大东北（副歌 I 后半、副歌 II）；土耳其 A 段 17–32 大提断奏八度跳进（照原谱左手）近似
- 大提琴在二分低音和 B 段八度八分之间加一层附点流行律动（附点四分 + 十六分 / 八分） — 情歌 A 段（原谱 slow soul「1⌒1 5 1」，附点四分 + 两个十六分）、茶汤 A 第二句 m14–16（附点四分 + 八分）
- 第二小提琴重复音，八分→十六分，3+3+2 重音（marcato, on the string） — 泪海、我不难过、情歌（A 段长音后直接十六分）、茶汤；大东北二提八分重复音同类。另外 Unravel（riff、间奏大提琴）和诀别书（大提、低提）也用 3+3+2 律动，但这两首是照钢琴原谱
- 一提在人声上方的高音区对位长线（con passione），最高冲到 G6 / A♭6 / A6 并持住 — 泪海（G6，F6 持一整小节）、我不难过（A♭6）、情歌（G6）、茶汤（G♯6–A6）；大东北副歌 I 前半一提（叠长笛）对位「飞」在合唱上方（到 G6）、我和我的祖国 29–31、53–55 一提高音对位，尾声 69 一提 D6–F6–A♭6 高线，同类
- 重音拍 / 燃点上大提琴八度双音砸低音 — 泪海 24–25（D♭2+D♭3、E♭2+E♭3 → F2+F3，中提同时十六分跨两八度琶音）、我不难过 20–21（先 C♭3+G♭3 五度，再 D♭2+D♭3 → E♭2+E♭3 八度，中提同时十六分琶音）、情歌 m8、m12（C2+C3，中提同时拉双音 B♭3+D4 / B♭3+F4；m13 是五度 F2+C3 配中提 A3+F4）
- 两把小提琴八度齐奏旋律，当「全开」 — 泪海 24、茶汤（尾奏；前奏第二遍见上面「前奏把钩子 / 动机奏两遍」）、大东北副歌 II、诀别书 13–16、25–30、37–39 和 41–44（41 全曲最大高潮，45 再加中提成三个八度）；土耳其 B 段、Unravel 桥段照原谱，冬风强奏时两件乐器八度成对（31–32、59–64）、55–56、83–84、92 三个八度齐奏照原作（这一条比较通用）
- 大提琴当旋律声部（低音交给低音提琴），和一提隔两个八度对答或齐奏 — 甲乙丙丁、茉莉花
- 前奏由中低音乐器先独唱主题，再交给一提高八度或高两个八度接 — 茉莉花（大提→一提）、甲乙丙丁（大提→一提，大提晚半小节对答）、我和我的祖国（中提→一提）；大东北序奏圆号低八度独奏副歌、冬风引子中提 sul G 独奏（原作），近似
- 中提琴拉主旋律，其余声部拨弦伴奏 — 我和我的祖国前奏 1–2（大提、二提拨弦，模仿竖琴）、土耳其 C 段 73–80 和 105–112
- 「嘭–恰」：低音落拍，内声部反拍（拨弦或拉弓） — 拨弦：大东北 5–21、我和我的祖国（前奏、主歌一，6/8）、土耳其（主题和进行曲第二遍改拨弦，当鼓用）；拉弓：诀别书 5 起（二提 + 中提原谱反拍律动）、土耳其主题（二提中提反拍断奏、大提只拉强拍）、Unravel 112–117（中提反拍双音）、我和我的祖国 49–51（中提三小节很轻的反拍）
- 十六分 / 快速音型在声部之间接力传递 — 我和我的祖国 24、56（大提→中提→二提琶音上行）、Unravel（华彩中提→二提→一提，崩落时 32 分音符瀑布接力到大提）、冬风（「风」逐小节下传，上行音型从中提、大提交给小提琴）、甲乙丙丁（「流水」中提和二提交替）
- 大提琴一弓滚奏三音和弦重击 — 土耳其（A2–E3–A3，当鼓）、Unravel（35、65）、冬风（大提 fz 拉 A 三音和弦，53–54 扫弦）
- 中提琴两弦 bariolage — 诀别书（所有十六分推动都这么写）、Unravel 62–64（空弦 G）
- 弦乐高八度叠人声主旋律，作为副歌第二遍的全开 — 大东北（副歌 II 一提高八度 + 二提原位，尾声一提叠女高高八度）、我和我的祖国（副歌二一提 8va 叠女高，尾声二提拉女低高八度）
- 多声部人声逐层开口：先一个声部（或女声齐唱）独唱，再女声由同度分成三度两部，一组人声哼「啊」「呜」衬另一组唱词，最后四部全开 — 大东北（主歌女声齐唱→18 分两部→22–25 男声领唱、女声哼「啊」→26 起四部）、我和我的祖国（主歌一女低独唱→副歌一女高首次开口→41–46 女高女低先同度再分三度、男声哼「呜」→副歌二全开；21–22 女低 + 男声哼三人清唱）
- sul tasto pp 弱奏的冷色长音 / 二重奏（多在高音区，有时加无揉弦） — 大东北序奏（一提 sul tasto 高音震音）、我和我的祖国 47–48（两把小提琴 sul tasto pp 在高处垫长音）、Unravel（前奏 0–4 两把小提琴 pp sul tasto 二重奏；八音盒段和尾声 118–121 中提、大提 sul tasto）、冬风（引子 3–4 四件 sul tasto 无揉弦圣咏）
- 弦乐震音（tremolo）铺底或推高潮 — 大东北（序奏一提、二提高音震音铺底；56 一提、二提、中提震音渐强进转调；77–78 一提 E6 震音收尾）、Unravel（崩落 78–79 一提、二提、中提震音）、冬风（59–60 大提，62、64 中提大提震音后砸减七，66–68 持续音震音轮流）
- 小提琴十六分上下琶音铺在旋律下（钢琴左手 / 竖琴式） — 我和我的祖国（间奏 33–36、副歌二二提十六分琶音，取自原谱钢琴左手）、大东北（间奏 48–51 一提和长笛十六分上下旋转琶音）、Unravel（间奏 50–57 二提整条右手十六分 spiccato，照原谱）
- 结尾渐宽到属七和弦，女高在高音上延长，再落主和弦 — 大东北（76 allarg.，D7 上女高 A5 延长→G6/9）、我和我的祖国（69 allargando，「中」B♭7 延长→「歌」E♭）
- 结尾不落完整主和弦、渐弱到无 — Unravel（停在 G + B♭，无五音，morendo）、诀别书（停在 C/B♭，C7 孤悬 al niente）；都照原谱
- 跳弓（spiccato）快速音型 — Unravel（间奏二提十六分 spiccato leggiero、八音盒二提 leggiero spicc.）、冬风 81–84（一提跳弓奏风）；音型都照原谱
