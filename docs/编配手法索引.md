# 编配手法索引（简表）

动笔构思新歌之前读完这一页，写完再对照一遍：新歌的织体、和声、前奏、高潮、尾奏不要和下面任何一首撞，尤其是第一节里已经用过两次以上的手法。用户否定过「照搬」（我不难过照搬泪海，被评「难听」，原话见 `AGENTS.md`「用户怎么提需求」）。

- 看着撞了：先看 `docs/编配手法索引_详细.md` 里那首歌的一节；还拿不准，再读那首歌的 `README.md`「编配思路」（Unravel 叫「编配要点」，另见 `unravel/ARRANGING.md`）。不在 `main` 上的歌用 `git show origin/<分支>:<目录>/README.md` 读（先 `git fetch origin '+refs/heads/*:refs/remotes/origin/*'`），茉莉花没有 README，看 `generate_score.py`。
- 这里还没有的歌（刚交付、没补进来的），直接读它的 README。
- 新歌交付时，照下面的格式在第三节末尾加一段（标志 / 织体 / 和声 / 前奏 / 高潮 / 尾奏）；它用到了第一节里的手法，就把它的名字补进那一条。
- 器乐改编（土耳其进行曲、Unravel、冬风、诀别书）的和声大多照原谱，列在这里是为了别把它们的配器手法搬进别的歌。

## 一、已经用过两次以上的手法

新歌默认不用。真要用，在 README 和回复里写清楚这首歌为什么需要它，而且不要和上一首连着用。

- 尾奏 IV(maj7/maj9/add9) → 借用 iv6（m6）→ I(add9)，内声部 6–♭6–5 半音下行（F 调里是 D–D♭–C） — 用了六次：茉莉花（尾声，中提 D–D♭–C）、泪海（中提 D–D♭–C）、甲乙丙丁（一提 D–D♭–C，中提持 D♭）、我不难过（A♭maj9→A♭m6→E♭，中提 C–C♭–B♭）、情歌（中提 D–D♭–C）、茶汤（Bm7→Dm6→A，中提 F♯–F–E）
- 副歌中段长音上放借用 iv（m6）当暗色 — 泪海（12、22 小节「幕」B♭m6）、我不难过（9、17 小节 A♭m(add9)→A♭m6）；诀别书 18、26 小节 B♭m6/C（中提 D–D♭–C）照原谱，算同色
- 尾奏一提 p/pp「eco」弱奏回声人声钩子、尾句或前奏动机 — 泪海、甲乙丙丁、我不难过、情歌、茶汤
- 终和弦 I(add9)，9 音放在内声部（中提双音或二提） — 泪海、甲乙丙丁、我不难过、情歌（大东北结尾 G6/9 是同一类）
- 前奏低声部长音铺底，一提 dolce 唱钩子，钩子在副歌长音上回声一次，尾奏 eco 再出现 — 泪海（人声钩子）、我不难过（人声钩子）、情歌（原曲弦乐钩子）、茶汤（原曲前奏动机，铺在 C♯4 持续音上）
- 前奏停在 V7sus4 / V9sus4（→V7）上，人声第 4 拍弱起进入 — 泪海（C7sus4→C7）、甲乙丙丁（C9sus4 留白）、我不难过（B♭7sus4）、情歌（C7sus4→C7）、茶汤（Esus4→E7）
- 前奏从 IV（maj7/maj9）起，不从主和弦起 — 甲乙丙丁（B♭maj9｜Am7 Dm7｜Gm7 C9sus4）和情歌（B♭maj7–Am7｜Gm7–B♭maj7/C）同调，进行几乎一样，低音都是 B♭–A–G–C；我不难过（A♭maj9）、茶汤（Dmaj9）也从 IV 起；大东北序奏（B♭add9）、诀别书（B♭maj7，原谱）同样从 IV 起
- 下行低音骨架 1–7–6–5–4–3–2–5（卡农式） — 泪海、情歌（同调，同一条 F–E–D–C–B♭–A–G–C）、茶汤（A–G♯–F♯–E–D–C♯–B–E，README 自己写了「同泪海骨架」）
- ♭VI–♭VII–I「燃点」：人声持主音，低音一路上行，同时大提琴八度双音 — 泪海 24 小节（D♭–E♭(add9)–F）、我不难过 20–21 小节（C♭maj7–D♭(add9)–E♭）
- 4–5–3–6（IV–V–iii–vi）当推进进行 — 我不难过（骨架）、茶汤（B 段「燃」点的主要来源）、大东北（「这嘎达土生土长」B♭maj7–Cadd9–Am7–Dm7）、诀别书（前奏和主题，原谱）；甲乙丙丁的 4–5–2–3–4–5–1 是近亲
- 中提琴八分分解和弦「波浪」铺底（legato, come onde），推进时加密成十六分 — 泪海、甲乙丙丁（副歌 9–12 八分，13–14 十六分）、我不难过、情歌、茶汤；同一族：茉莉花「如水」八分四音波纹（中提、二提、大提轮流拉）、甲乙丙丁前奏「流水」（中提和二提交替十六分）、大东北副歌中提八分分解、诀别书 9–12
- 副歌前半同一套组合：大提二分音符下行低音 + 中提八分波浪 + 二提长音「光环」（常拉大七度）+ 一提休止，只在人声长音处（多为高八度）回声钩子 — 泪海 6–9、我不难过 5–8、茶汤 10–13；甲乙丙丁 9–12（二提长音、一提休止到「丁」高八度托住）、茉莉花 A 段（一提只在 10、14 小节长音处高八度回声）形状相同；情歌 A 段部分相同（中提波浪 + 二提长音）
- 两把小提琴三度 / 六度平行双线 — 泪海 10–13、甲乙丙丁（12 小节六度小句，高潮时二提在下方三度、六度陪衬）、我不难过 9–12、情歌前奏第二遍（二提在下方配三度）、我和我的祖国（5–7 小节一提 + 中提，32、64 小节两把小提琴）；茉莉花 B 段三、四度交替，土耳其照原谱三、六度，都近似
- 高潮前一小节：两把小提琴平行十六分上行音阶，中提、大提十六分（重复音或八度交替）推属和弦 — 泪海 15（三度）、我不难过 12（三度）、茶汤 17（四度平行五声音阶，下面 A7）、我和我的祖国 32、64（三度，取自原谱钢琴过门）；大东北 30 小节一提十六分上行冲进副歌，同类
- 高潮前最后一拍弦乐 / 全体停（G.P.），人声清唱，下一拍全奏砸进去 — 泪海 15、我不难过 12、情歌 8（「还好」）、茶汤 17（「僵」）、大东北 57（转调前 G.P.）、诀别书 40（G.P.→41 Grandioso）；我和我的祖国 21–22 的清唱有意放在主歌中段，位置不同
- 「层层加码」分工表：每段每件乐器换更密的节奏型（长音→八分→十六分） — 泪海、我不难过、情歌、茶汤（三首 README 都有同一张表）；诀别书（长音→八分→十六分 bariolage）同类
- 第二遍 / B 段大提琴八分音符八度跳进（marcato） — 泪海、我不难过、情歌、茶汤、大东北（副歌 I 后半、副歌 II）
- 第二小提琴重复音，八分→十六分，3+3+2 重音（marcato, on the string） — 泪海、我不难过、情歌、茶汤；大东北二提八分重复音同类。另外 Unravel（riff、间奏大提琴）和诀别书（大提、低提）也用 3+3+2 律动，但这两首是照钢琴原谱
- 一提 con passione 高音区长线，最高冲到 G6 / A♭6 / A6 并持住 — 泪海（G6，F6 持一整小节）、我不难过（A♭6）、情歌（G6）、茶汤（G♯6–A6）
- 重音拍 / 燃点上大提琴八度双音砸低音，中提同时拉双音 — 泪海 24、我不难过 20–21、情歌 m8、m12、m13
- 两把小提琴八度齐奏旋律，当「全开」 — 泪海 24、茶汤（前奏第二遍、尾奏）、大东北副歌 II、诀别书 25–30 和 37–39；土耳其 B 段、Unravel 桥段照原谱（这一条比较通用）
- 大提琴当旋律声部（低音交给低音提琴），和一提隔两个八度对答或齐奏 — 甲乙丙丁、茉莉花
- 前奏由中低音乐器先独唱主题，再交给一提高八度或高两个八度接 — 茉莉花（大提→一提）、甲乙丙丁（大提→一提，大提晚半小节对答）、我和我的祖国（中提→一提）；大东北序奏圆号低八度独奏副歌、冬风引子中提 sul G 独奏（原作），近似
- 中提琴拉主旋律，其余声部拨弦伴奏 — 我和我的祖国前奏 1–2（大提、二提拨弦，模仿竖琴）、土耳其 C 段 73–80 和 105–112
- 拨弦「嘭–恰」：低音拨落拍，内声部拨反拍 — 大东北 5–21、我和我的祖国（前奏、主歌一，6/8）、土耳其（主题和进行曲第二遍改拨弦，当鼓用）
- 十六分 / 快速音型在声部之间接力传递 — 我和我的祖国 24、56（大提→中提→二提琶音上行）、Unravel（华彩中提→二提→一提，崩落时 32 分音符瀑布接力到大提）、冬风（「风」逐小节下传，上行音型从中提、大提交给小提琴）、甲乙丙丁（「流水」中提和二提交替）
- 大提琴一弓滚奏三音和弦重击 — 土耳其（A2–E3–A3，当鼓）、Unravel（35、65）、冬风（大提 fz 拉 A 三音和弦，53–54 扫弦）
- 中提琴两弦 bariolage — 诀别书（所有十六分推动都这么写）、Unravel 62–64（空弦 G）
- 弦乐高八度叠人声主旋律，作为副歌第二遍的全开 — 大东北（副歌 II 一提高八度 + 二提原位，尾声一提叠女高高八度）、我和我的祖国（副歌二一提 8va 叠女高，尾声二提拉女低高八度）
