## 四个脚本共用的音乐时间点

时间是歌曲秒数，和 MP3 一致，详细数据见 `timing.json`。

| 秒 | 音乐 |
|---|---|
| 0–3.3 | 很轻的长音 → 第一帧必须有钩子字幕 |
| 3.3–16.3 | 前奏，第一小提琴拉「你怎么舍得」的旋律 |
| 16.3–19.6 | 前奏最后一小节 |
| 19.6–27.5 | 「你怎么舍得让我的泪流向海」，「泪」在 23.1 秒 |
| 27.5–35.6 | 「付出的感情永远找不回来」，「找不回来」在 33.1 秒 |
| 35.9–43.7 | 「你怎么舍得让我的爱流向海」 |
| 43.7–47.8 | 「伤心的往事一幕幕」，两个「幕」在 46.0 和 46.5 秒 |
| 47.8–55.9 | 「就像潮水将我淹埋」 |
| 54.9–60.0 | 过门，弦乐上行渐强 |
| **60.0–61.0** | **弦乐全停，只剩清唱「你怎么」** |
| 61.0 | 全奏进入第二遍（高燃） |
| 61.0–88.5 | 第二遍的前四句；87.5 秒是全曲最高音 |
| 88.5–100.1 | 「就像潮水将我淹埋」：93.6 秒 D♭，95.6 秒 E♭，97.8 秒落到 F，全曲最大的高潮 |
| 101.5 | 尾奏，第一小提琴弱奏回声 |
| 104.6 | B♭m6，全曲最暗的一个和弦 |
| 107.0 | 最后的和弦 |
| 112.5–118.8 | 混响尾巴 |

## ① Clawd（升级表情）×《还给海》

- **角色**：沿用上一支的正面造型：方块身体，两只竖条眼睛，身上一条竖向分块线。新增的表情：
  - 眨眼、闭眼；
  - 眼睛变成弯弧，表示释然；
  - 低头；
  - 很淡的脸红；
  - 眼下一点水光。
- **故事背景**：她把两人在礁石潮池里一起捞的小蓝鱼养在鱼缸里。分开以后，她决定把它还给海。
- **脚本**：见 `STORY.md`，表情按下面几个点落：

  | 秒 | 表情 |
  |---|---|
  | 23.1 | 眼下水光 |
  | 33.1 | 回忆化开时慢慢眨一下眼 |
  | 60.0 | 闭眼再睁开，做决定 |
  | 97.8 | 被光淹没时闭眼 |
  | 101.5 | 挥手，眼睛弯成弧 |
  | 104.6 | 低头 |

- **优点**：和《下一站》连成系列；引擎本来就有 Clawd，最快最稳。
- **风险**：Clawd 没有嘴，表情有限；抖音上大多数人不认识它；它是 Anthropic 的形象，账号以后要商业变现时要注意。

## ② 原创女孩 ×《半把伞》

- **角色**：短发、芥末黄雨衣、红雨靴、透明伞。可以做成账号自己的固定形象，以后每首歌都用她。
- **故事背景**：她和他在海边小城住过一年，下雨时总是共撑一把伞，伞总往他那边歪。分开三个月了，她一个人撑伞，伞还是习惯性地往右边偏，左肩一直是湿的。
- **钩子字幕**（第一帧）：「分开三个月，她的伞还是往右边歪」

| 秒 | 画面 |
|---|---|
| 0–3.3 | 雨中的海边小街，一把透明伞下只有她一个人，伞明显往右边偏 |
| 3.3–16.3 | 她沿着海边走，经过两人常去、现在关着门的面包店 |
| 16.3–19.6 | 红灯前停下，习惯性地侧头看右边：空的 |
| 19.6–27.5 | 雨打在伞上。「泪」（23.1）她抬头看天，脸上分不清是雨还是泪；街边的雨水顺着坡流向海 |
| 27.5–35.6 | 暖色回忆：两人挤在同一把伞下，她把伞往他那边推，他笑着推回来。「找不回来」（33.1）回到现实，伞下只有她 |
| 35.9–43.7 | 走到两人以前坐的海边长椅，长椅湿透了 |
| 43.7–47.8 | 橱窗玻璃里闪过两人的背影（46.0、46.5 两个画面） |
| 47.8–55.9 | 海风变大，雨斜着打过来 |
| 54.9–60.0 | 风越来越大，伞被吹得往外翻，她双手抓紧 |
| **60.0–61.0** | **雨滴停在空中。她第一次注意到自己湿透的左肩** |
| 61.0 | 她松开了手 |
| 61.0–76.3 | 伞被风卷起，翻飞着飞向海面；她站在雨里，没有追 |
| 76.5–88.5 | 她慢慢张开双手淋雨；雨幕里闪过往事。最高音（87.5）时，远处海面上的伞转了一圈，像最后一次回头 |
| 88.5–97.8 | 大雨，浪拍上岸。落到 F（97.8）时云层裂开，一道阳光照在海面和她身上 |
| 98–100.1 | 雨停了。她浑身湿透，**两边肩膀一样湿**，第一次不再给谁留位置 |
| 101.5 | 路边的水洼倒映出晴天，她轻轻跳过去 |
| 104.6 | 路过面包店，看了一眼 |
| 107–118.8 | 她继续往前走，阳光里的背影。远处海面上那把伞越漂越远，画面淡出 |

- **优点**：情歌的共鸣最强，评论区最容易出现「我也是」；角色可以长期用。
- **风险**：要重新设计角色，人物的走路、表情也比方块角色难画很多。

## ③ 小狗 ×《等潮》

- **角色**：奶油色的小土狗，脖子上系着一条红色毛线围巾。
- **故事背景**：男孩搬去了大城市。走的那天，他在渡轮码头把自己的红围巾系在小狗脖子上。从那以后，小狗每天傍晚都跑到码头尽头等渡轮。（不涉及死亡，只是离开。）
- **钩子字幕**：「他走的那天，把围巾留给了它」

| 秒 | 画面 |
|---|---|
| 0–3.3 | 码头尽头，戴红围巾的小狗坐着看海 |
| 3.3–16.3 | 几个傍晚快速接在一起：同一个位置，天色和天气不同，它每天都准时来 |
| 16.3–19.6 | 远处一声船笛，它竖起耳朵 |
| 19.6–27.5 | 渡轮靠岸，人们下船，它伸长脖子在人群里找。「泪」（23.1）它眼睛里映着船灯 |
| 27.5–35.6 | 暖色回忆：男孩抱着它在码头追海鸥，给它系上围巾。「找不回来」（33.1）下船的人都走光了 |
| 35.9–43.7 | 天黑了，奶奶提着灯来接它，它趴下不肯走 |
| 43.7–47.8 | 夜里的码头，两盏灯在水面上晃（46.0、46.5） |
| 47.8–55.9 | 潮水涨上台阶，它后退一步，又回到原地 |
| 54.9–60.0 | 起风，浪越来越高，奶奶在岸上喊它 |
| **60.0–61.0** | **时间静止。它看见水里自己的倒影：戴着围巾，只有一只狗** |
| 61.0 | 一道大浪打上码头，风把红围巾吹走，飞向海面 |
| 61.0–76.3 | 它追到码头尽头，围巾落在海上越漂越远；它停在边上，没有跳下去 |
| 76.5–88.5 | 浪花里闪过往事，男孩离开的背影。最高音（87.5）时，它对着大海叫了一声，全片只叫这一次 |
| 88.5–97.8 | 风雨和大浪。落到 F（97.8）时雨停云开，月光铺在海上 |
| 98–100.1 | 它安静地坐着，脖子上空了 |
| 101.5 | 远处一只海鸥叼起漂着的红围巾，飞向远方，像替它把思念送出去 |
| 104.6 | 奶奶蹲下摸摸它的头 |
| 107–118.8 | 它跟着奶奶往岸上走，回头看了一眼海。码头空了，只剩浪声 |

- **优点**：抖音上动物题材的转发意愿最高，「等待」最容易让人代入。
- **风险**：催泪太重会显得刻意，要按上次的原则克制。不能暗示男孩去世。

## ④ 雪人 ×《雪人去了海》

- **角色**：两个雪球，煤球眼睛，胡萝卜鼻子，树枝手，围着一条蓝色毛线围巾。
- **故事背景**：冬天，两个人在海边堆了这个雪人。她把自己的蓝围巾给它围上，说「明年冬天再来看你」。后来她没有再来。春天到了，雪人一点点化成水，流进了海。
- **钩子字幕**：「春天来了，它决定去海里找她」
- **为什么和这首歌最贴**：
  - 「泪流向海」就是字面意思，雪人化的水一路流进海里；
  - 融化的过程正好跟着音乐一层层加强。

| 秒 | 画面 |
|---|---|
| 0–3.3 | 海边雪地上，戴蓝围巾的雪人，身下一道细细的水痕流向海 |
| 3.3–16.3 | 回到那个冬夜：两个小小的身影在海边堆雪人，给它围上围巾，挥手离开（远景剪影） |
| 16.3–19.6 | 季节快进：雪一天天变少，太阳越来越高 |
| 19.6–27.5 | 雪人开始融化。「泪」（23.1）一滴水从煤球眼睛下滑落，顺着沙滩流向海 |
| 27.5–35.6 | 融化的水里映出堆雪人那晚的画面。「找不回来」（33.1）一根树枝手臂掉了 |
| 35.9–43.7 | 它又小了一圈，围巾显得更大 |
| 43.7–47.8 | 沙滩上两人留下的两处脚印，被潮水先后抹平（46.0、46.5） |
| 47.8–55.9 | 潮水漫上来，碰到它的底座 |
| 54.9–60.0 | 暖风，阳光越来越强，它化得越来越快，水流越来越粗 |
| **60.0–61.0** | **最后一片雪花停在空中。它用剩下的那只手把围巾按在胸口** |
| 61.0 | 一道浪涌上来，把它整个卷进海里 |
| 61.0–88.5 | 镜头进入海水：雪人化成的水在海里流动、发光，蓝围巾在水里漂；第一遍里映在融水中的往事，这次大大地映在整片海里。最高音（87.5）时围巾在水面上展开，像一面旗 |
| 88.5–97.8 | 海水把光和围巾一起托向远方。落到 F（97.8）时太阳跃出海面，一片金光：它成了海的一部分 |
| 98–100.1 | 平静、发亮的海面 |
| 101.5 | 很远的另一片海滩，一只手从浪边捡起那条蓝围巾。只拍手，不拍脸，留白：是不是她？ |
| 104.6 | 那只手停住了 |
| 107.0 | 她把围巾围上，望着海（只拍背影） |
| 112.5–118.8 | 又一个冬天，同一片海滩下起了雪。最后一帧接回第一帧的雪地，可以首尾循环 |

- **优点**：画面最有记忆点，在抖音上少见；角色是简单的几何形状，好画；没有版权问题。
- **风险**：融化可能被理解成「死去」，必须把它拍成「去海里找她」这样的转变，结尾要亮。

## 云端的建议

| 看重什么 | 选哪个 |
|---|---|
| 和这首歌的贴合度、画面记忆点 | ④ 雪人 |
| 系列感、制作最快 | ① Clawd |
| 情歌共鸣、以后做账号形象 | ② 女孩 |
| 抖音转发 | ③ 小狗 |

制作难度从易到难：① Clawd < ④ 雪人 < ③ 小狗 < ② 女孩。
