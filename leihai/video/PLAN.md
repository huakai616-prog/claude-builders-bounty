## 目标

用用户在 Logic 里混好的《泪海》MP3，做一支和《甲乙丙丁·下一站》同样做法的动画视频：

- 竖屏 1080×1920，24fps。
- 上方：Clawd 水彩故事动画（ClaudeAnimationBase，代码渲染）。
- 中间：歌词，整句淡入淡出，唱到的字逐字变色。
- 下方：四个弦乐声部的手写风格滚动谱。
- 最下方：曲名与署名。

上次的做法记录在用户手上的《甲乙丙丁·下一站》制作复盘文档里。那份文档是上次在 Mac 上写的，**开工前向用户要这份文档，或者在 Mac 上找到它，并先读完**。
上次的完整工程在用户 Mac 的「文稿/视频创作/甲乙丙丁_下一站_完整版」文件夹，包括场景代码、合成器 `composite.cjs`、手写谱脚本和字体。按复盘的要求：

- 旧工程、原始素材和旧成片都保留，在副本里改，新东西另存版本；
- 旧工程的部分依赖是用符号链接和本机绝对路径引用的，复制前先核对。

## 已经核对过的时间（云端测的）

- **MP3 与谱面时间轴完全重合**：MP3 从 0 秒开始，没有前置空白。
- **对齐方法**：用 `leihai/build.py` 的速度表（`TEMPI`）和 `sec_at()` 就能换算，误差在 0.03 秒以内，结尾的渐宽和渐慢也对得上。所以歌词逐字时间和谱面滚动锚点直接从 `build.py` 算，不用像上次那样在尾段靠频谱估计。
- **实测对照点**（MP3 秒数 / 谱面秒数）：

  | 事件 | MP3 | 谱面 |
  |---|---|---|
  | 弦乐全停 | 60.00 | 60.00 |
  | 清唱「你」 | 60.27 | 60.25 |
  | 清唱「怎」 | 60.52 | 60.51 |
  | 清唱「么」 | 60.78 | 60.76 |
  | 全奏进入 | 61.04 | 61.02 |
  | 「埋」收尾 | 100.1 | 100.12 |

- **结尾**：音乐约在 112.5–113 秒结束。之后到约 115 秒是混响尾巴，再往后基本是静音，文件总长 118.83 秒。
- **歌词**：共 102 个字（一遍副歌 51 字，唱两遍），分 10 句，见 `leihai/output/泪海_副歌_歌词字幕.srt`。逐字时间用 `build.py` 里的 `syllables()` 加 `sec_at()` 生成。

## 制作时必须守住的（来自上次的复盘和用户反馈）

- **分层**：上方动画讲故事，下方乐谱展示编配，两者内容独立。
- **五线谱不能当道具**：不能变成角色站的电线、舞台或道具。上次「站在五线谱电线上」的方向被用户否定了。
- **表演要含蓄**：靠视线、停顿、手臂和空位表达，不要夸张哭喊、爱心和强行团圆。「泪海」字面上很容易拍成大哭，要用潮水、空位这类含蓄的画面，眼里最多一点水光。
- **流程**：讨论故事 → 写分镜（`STORYBOARD.md`）→ 10 秒样片 → 按反馈改 → 完整版 → 封面。先出关键帧和转场的静帧检查，再渲染全帧。
- **谱面**：必须来自真实总谱（PDF 加 MusicXML），不让图像模型凭空画「像乐谱的装饰」。这次是四个声部，上次是五个，版式要重排。
- **重新渲染要清旧帧**：渲染器会跳过已经存在的帧，改了动画以后要先清掉受影响的旧帧，或者换一个输出目录。
- **验证分开做**：技术指标、同步数据、音频比对、画面抽查分别检查。没有人工逐音试听过，就不要说试听过。
- **成片不要提交进 git**：视频有几十 MB。成片直接给用户，仓库只放代码、分镜、时间数据这些小文件，比如放在 `leihai/video/`。
