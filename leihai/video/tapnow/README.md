# 《泪海》× 小狗《等潮》：用 TapNow 做画面，脚本对齐音频

用户 2026-09-28 定下：
- **主角**：小狗阿旺，故事是《等潮》。剧情见 `../CHARACTERS.md` 第 ③ 节。
- **版式**：沿用 A2。上半部分是动画，中间是歌词，下半部分是四行手写谱，署名突出编配。
- **画风**：日系手绘动画电影感。
- **画面来源**：云端用代码画的画质不够，改用 TapNow 生成。

## 分工

| 谁 | 做什么 |
|---|---|
| 你（在 TapNow 里） | 照 `分镜与提示词.md` 生成镜头：必做 28 个，其中 27 段视频、1 张图。下载后按镜头号命名 |
| `assemble.py` | 把镜头按 MP3 的秒数卡进时间线：长的剪掉，短的放慢一点。再加上逐字变色的歌词、滚动的弦乐谱和署名，输出 1080×1920 的抖音竖屏 |

`预览_分镜占位版.mp4`（在聊天里发过）就是成片的骨架：
- 音乐、歌词、谱面、署名都是真的；
- 每个镜头的位置先用写着画面内容的色卡占着；
- 把 TapNow 的片段放进来，色卡就会换成真画面。

## 在 TapNow 里怎么做

模型和按钮的名字以 TapNow 里当时显示的为准，下面说的是做法。

### 生成前的设置

- **画幅选 4:3，没有就选 16:9。** 镜头在成片里只占上半部分（1080×930）：
  - 4:3 左右只裁掉一点点；
  - 16:9 左右各裁掉约 1/6，重要的东西不要放在最左、最右。
- **画面最下面约 15%** 会淡进纸色、叠上歌词，关键动作不要放在最底下。
- **清晰度**选 1080p（如果有这个选项）。
- **生成声音**的开关关掉，省积分。成片只用你的 MP3。
- **时长**按分镜表写的来，大多数是 5 秒。生成得比需要的长没关系，脚本会剪掉多余的。

### 第一步：定妆（最重要）

1. 用 R1 的提示词出「阿旺定妆图」三视图。多出几张，挑最喜欢的一张，它决定阿旺在整部片子里的样子。
2. 在这张图上改图，得到 R2「阿旺无围巾」。围巾被风吹走以后的镜头都用它。
3. 用 R3 出「码头定场图」。再在它上面改出 R4–R6：夜、暴风雨、月夜。这样每个时段的码头都是同一个地方。
4. 男孩（R7）、奶奶（R8）各出一张背影参考。

图片模型选支持参考图的，比如 Nano Banana、Seedream 这一类。

### 第二步：逐个镜头生成

每个镜头分两步：

1. **首帧图**：
   - 新建图片节点，粘贴「首帧提示词」；
   - 把「参考图」那一栏写的定妆图连进来；
   - 生成 2–4 张，挑一张。
2. **视频**：
   - 把挑好的首帧图接到视频节点（图生视频），粘贴「视频提示词」；
   - 时长照表；
   - 视频模型选画质好、动作稳的，比如 Seedance、可灵。整部片子尽量用同一个模型，画风才统一。

小技巧：
- **先图后视频**：图片便宜、视频贵，首帧图满意了再生成视频。
- **连着的镜头改图接着做**：暴风雨几镜（S19–S24）、月夜几镜（S31–S35），先出其中一镜的首帧，再在上面改图得到下一镜，前后更连贯。
- **阿旺走样就重来**：视频里颜色、耳朵、围巾变了，换一张首帧重新生成，不要硬用。
- **S20 只要一张图**：这一镜是「时间静止」，脚本会给它加一个很慢的推近。
- **可省的镜头可以先不做**：标「可省」的 7 个，脚本会借用别的镜头，积分够了再补。

### 第三步：下载、命名

- **文件名以镜头号开头**：`S01.mp4`、`S02.mp4`……写成 `S07_第二版.mp4` 也可以。
- **S20 是图片**：存成 `S20.png`。
- **放在哪**：全部放进这个文件夹下的 `clips/`。

## 合成

在装了 ffmpeg 的电脑上运行。Mac 上先装好 ffmpeg 和两个 Python 库：

```bash
brew install ffmpeg
pip3 install numpy pillow
```

然后在这个文件夹里运行：

```bash
cd leihai/video/tapnow
python3 assemble.py --check                                 # 看哪些镜头已经有了、还缺哪些
python3 assemble.py --audio ~/Desktop/泪海.mp3                # 出全片：out/泪海_等潮_竖屏.mp4
python3 assemble.py --audio ~/Desktop/泪海.mp3 --from 58 --to 66   # 只出一段看看
python3 assemble.py --stills 23.5,60.5                      # 只导出这几个时间点的静帧
```

不想自己敲命令，有两个办法：
- 把片段交给 Mac 上的 Claude，说「照 leihai/video/tapnow/README.md 合成」；
- 把片段发到云端会话里，由云端来拼。

### 脚本自动做的事

- **切点**：每个镜头从第几秒到第几秒，都卡在小节线或歌词的字上，时间来自 `../timing.json`。
- **时长**：
  - 片段比需要的长，就从头开始剪掉多余的；
  - 短了，最多放慢到 85%，再不够就停在最后一帧；
  - `--check` 会提示哪个片段太短。
- **转场**：
  - 进回忆时叠化（S09、S25），回到现实时叠化（S11、S27）；
  - 97.8 秒落到 F 的时候白光一闪（S31）；
  - 最后 2.5 秒画面淡出。
- **钩子字幕**：前 5 秒在画面上方显示「他走的那天，把围巾留给了它」。
- **歌词**：整句淡入，唱到的字变成赭红色。
- **谱面**：四行弦乐谱跟着音乐滚动。60.0–61.0 秒弦乐全停、只剩清唱，谱面跟着变淡。
- **署名**：「弦乐编配　花开当富贵」放大加粗，没有印章。
- **声音**：只用 `--audio` 给的 MP3，镜头自带的声音全部丢掉。

### 现在的谱面是占位

谱面现在是 MuseScore 的印刷谱加上手绘抖动，和示意图一样。要换成上次 GPT 做的 Inkpen2 手写谱，得在 Mac 上把手写谱排成一长条图，替换 `assets/score_strip.png` 和 `assets/score_strip.mpos`（每小节的位置）。做法见 `../PLAN.md`。

## 发抖音前

- 勾选「作品含 AI 生成内容」：画面是 AI 生成的，歌手小梅也是 AI。
- 成片里有你的混音。要不要提交进公开仓库，由你决定；脚本默认输出到 `out/`，这个文件夹不会提交。

## 文件

| 文件 | 用途 |
|---|---|
| `分镜与提示词.md` | 每个镜头的时间、画面、参考图、可以直接复制的提示词。由 `shots.py` 生成 |
| `shots.py` | 分镜的单一数据源。改了切点或文字，运行 `python3 shots.py` 重新生成文档 |
| `assemble.py` | 合成脚本 |
| `make_fonts.py` | 改了歌词、署名或钩子字幕以后，重新裁字库（要在装了思源宋体的 Linux 上运行） |
| `assets/` | 谱面长条图、每小节位置、裁过的思源宋体（SIL OFL 1.1，见 `assets/OFL.txt`） |
| `clips/` | 放 TapNow 的片段（不提交） |
| `out/` | 成片输出（不提交） |
