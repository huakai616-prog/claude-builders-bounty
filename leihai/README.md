# 泪海（副歌）· 人声与弦乐四重奏

原曲：许常德、李忠屏 词，李忠屏 曲，许茹芸 演唱。
原谱 1=D，按要求**整体改成 F 大调（1=F）**，4/4，♩=59。
编制：人声 + Violin I / Violin II / Viola / Violoncello（弦乐四重奏）。
风格：综艺抒情高燃。副歌唱两遍，第一遍抒情，第二遍全开。

人声在第 5 小节第 4 拍弱起「你怎么」进入。

## 结构

| 段落 | 小节 | 内容 |
|---|---|---|
| 前奏 Intro | 1–5 | 空五度的 Fsus2 长音铺底，第一小提琴在中音区唱出副歌的钩子「你怎么舍得」，第 5 小节停在 C7sus4 → C7 上，人声弱起 |
| 副歌 I（抒情） | 6–14 | 你怎么舍得让我的泪流向海……就像潮水将我淹埋 |
| 过门 Lift | 14 第 3 拍–15 | 两把小提琴三度平行的十六分音符上行音阶，中提琴、大提琴十六分音符重复音推 C 属音，从 p 渐强到 ff。**第 15 小节第 4 拍弦乐全停**，人声清唱「你怎么」 |
| 副歌 II（高燃） | 16–24 | 弦乐全奏落拍进入，结尾「淹埋」走 D♭ → E♭ → F（♭VI – ♭VII – I）的燃点进行，渐宽 |
| 尾奏 Coda | 25–27 | 人声收住后，第一小提琴弱奏回声「你怎么舍得」的钩子，B♭maj9 → B♭m6 → F(add9) 结束，渐慢 |

## 编配思路

- **和声简单而高级**：骨架是最常见的下行低音线 F – C/E – Dm7 – Dm7/C – B♭maj7 – Am7 – Gm7 – C7（1 – 5/7 – 6 – 6/5 – 4 – 3 – 2 – 5），靠色彩音和几处借用和弦出高级感：
  - 第一句的 F 上第二小提琴拉 E（大七度），听起来像 Fmaj9。
  - 第二句的低音换成半音下行：Dm7 → **G9/B** → **B♭m6**（借用的小四级）→ F/A → Gm7 → C7。
  - 两遍副歌结尾不同。第一遍「淹埋」回到 F，接 B♭maj7 → Gm7 → C7sus4 过门。第二遍「淹埋」走 **D♭ → E♭(add9) → F**，人声的 F 长音横跨三个和弦，「淹」的 G 落在 D♭ 上是 #11。
  - 结尾 B♭maj9 → B♭m6 → F(add9)。中提琴 D → D♭ → C 半音下行，第一小提琴 D♭ → C（小六级回到五级）。
- **层层加码（综艺高燃的核心）**：

  | 段落 | 大提琴 | 中提琴 | 第二小提琴 | 第一小提琴 |
  |---|---|---|---|---|
  | 副歌 I 前半 | 二分音符低音 | 八分音符分解和弦（波浪，“come onde”） | 长音光环 | 只在人声长音「海」时回声钩子 |
  | 副歌 I 后半 | 低八度，带经过音 | 高潮前改十六分音符 | 与第一小提琴三、六度双线 | 对位旋律 |
  | 副歌 II 前半 | 八度跳进的八分音符律动 | 八分音符波浪 | 八分音符重复音 | 高音区对位旋律（C6–F6） |
  | 副歌 II 后半 | 同上 | 十六分音符波浪 | 十六分音符，3+3+2 重音 | 最高到 G6，第 22–23 小节在 F6 上持住一整小节，才落到 E6 再进 D♭ |

- **呼应**：弦乐的旋律只在人声的长音和气口里动（「海」「远」「来」「幕」「水」），人声在唱字时弦乐多是长音，不抢词。
- **清唱留白**：第 15 小节弦乐在第 4 拍全部停下，只剩人声清唱「你怎么」，下一拍全奏砸进副歌 II。这是综艺编曲最常用的「燃点」。
- 各声部都在舒适音区：第一小提琴最高 G6，大提琴最低 C2（空弦），中提琴最低 C3。人声 C4–D5。
- 脚本会自动检查：每个十六分音符的纵向音程（包括和人声之间）没有小二度或小九度冲突；任意两个声部之间，包括和人声之间，都没有平行五度和平行八度。只有第 24 小节两把小提琴八度齐奏是有意的。

## 在西贝柳斯里打开

西贝柳斯的 `.sib` 工程只能在西贝柳斯里存出来，这里给的是 MusicXML，是西贝柳斯官方支持的导入格式。

1. `文件 → 打开`，选 `泪海_副歌_人声弦乐四重奏.musicxml`（或者直接拖进西贝柳斯）。
2. 导入对话框如果有版面相关的选项，选保留文件里的版面。各声部已经带了乐器音色 ID（strings.violin / strings.viola / strings.cello），会自动对应到正确的乐器。
3. 打开后 `文件 → 另存为`，就得到 `.sib` 工程。
4. 版面：A4 竖版，6 毫米谱表，密集段落 3 小节一行，段落开头换行。如果想让西贝柳斯自己排，全选后执行 `版面 → 格式 → 解锁格式`，再执行 `外观 → 重置设计 / 重置位置`。

## 在 ACE Studio 里呈现

1. 导入 `泪海_副歌_人声弦乐四重奏_全轨.mid`，保留速度信息（结尾有渐宽和渐慢）。
2. 人声轨：加载 **Vocal Synth**，选一个中文女声（抒情、气声多一点的唱法更接近原唱）。歌词已经在音符上，拖腔音符标的是 `-`，会连着上一个字唱。如果歌词是乱码，删掉这一轨，改导 `泪海_人声_带歌词_GBK编码备用.mid`。也可以单独把 `泪海_人声_带歌词.mid` 拖进一条人声轨。
3. 四个弦乐轨：都加载 AI 乐器 **String Section**，speaker 分别选 **Violins I / Violins II / Violas / Celli**。演奏法保持默认的智能模式（smart mode）即可，这版没有拨弦，也没有弱音器。
4. 弦乐的 AI 渲染在播放时进行，被静音或独奏的轨不会渲染；弦乐听起来是钢琴声，说明那条轨还没加载音源。

## 修改后重新生成

```bash
pip install music21 mido
python3 build.py          # 生成全部文件到 output/
python3 build.py --check  # 只检查音域、声部冲突和平行五八度
```

乐谱数据都写在 `build.py` 里，每小节一行，时值以十六分音符为单位。改一处，MusicXML、MIDI 和字幕会一起更新。
PDF 预览和试听 mp3 是用 MuseScore 3 和 FluidSynth 另外渲染的：

```bash
mscore3 -o output/泪海_副歌_总谱预览.pdf output/泪海_副歌_人声弦乐四重奏.musicxml
fluidsynth -ni -F preview.wav /usr/share/sounds/sf2/FluidR3_GM.sf2 output/泪海_副歌_人声弦乐四重奏_全轨.mid
```

> 说明：原谱的副歌是「你怎么舍得让我的泪流向海」到「就像潮水将我淹埋」（带弱起「你怎么」），原谱里这段本来就有反复和 D.S.，所以这里唱了两遍：第一遍用一房的结尾，第二遍用二房的结尾。如果只要唱一遍，告诉我，我把第 14–24 小节换成一个直接进尾奏的结尾。
