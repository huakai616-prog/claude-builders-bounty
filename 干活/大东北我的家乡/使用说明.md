# 大东北我的家乡 · 成品文件

迪士尼风格交响乐 + 传统四声部合唱。F 大调，最后一遍副歌和尾声转 G 大调。78 小节，约 2 分 38 秒。
三个文件夹对应三件事：Instrument X 乐队、ACE Studio 合唱、西贝柳斯总谱。所有文件都从第 1 小节（0:00）开始。

---

## 1_InstrumentX乐队MIDI

### 该导入哪个文件

1. **先试 `00_全乐队15轨_InstrumentX.mid`**：15 条轨在一个文件里，每轨一个 MIDI 通道。轨名写了该选的扩展包，例如 `Violin I (Instrument X: Violin 1)`。
2. 导入后看 Instrument X 的速度栏：**第 5 小节是不是 128**。
   - 是：说明速度变化读进来了，就用这一套。
   - 还是 120 或别的固定速度：用户反映 Instrument X 目前多半不读 MIDI 里的速度变化。这时删掉刚导入的轨，把工程速度设成 **120、4/4**，改导 **`按秒对齐_固定120BPM_备用/`** 里的同名文件。
     - 这套文件把所有速度变化（♩=72 → 128、渐慢、延长）都换算进了音符的位置。渲染出来的音频和合唱逐秒对齐，只是 Instrument X 里的小节线对不上谱。
   - 第三种办法：在 Instrument X 的速度栏手动输入下面的速度表，然后继续用第一套文件。
3. 单轨文件 `01`–`15` 是备用：一次拖一个，拖到第 1 小节。
4. `MusicXML备用_每轨一个/` 是另一种导入方式。MusicXML 里带着震音、颤音、跳音等记号，有可能直接变成 Instrument X 的演奏法。

- unison 数只是起点。有用户反映弦乐叠得多了会有“相位感”，听着发虚就减少人数，或改用 Instrument X 自带的 String Ensemble 预设。
- 全部是实际音高（C 调），每轨都是单旋律。连线内的音符首尾相接、不重叠，这样 Instrument X 能识别连奏。
- Instrument X 是导入后离线渲染的，等所有轨都渲染完再听。

### 需要手动设的演奏法

Instrument X 没有键位开关，演奏法要逐个音符设。表里给了按秒对齐版里对应的时间。

| 演奏法 | 声部 | 谱上小节 | 时间 |
|---|---|---|---|
| 拨弦 pizzicato | 第二小提琴、中提琴、大提琴、低音提琴 | 5–21 | 0:14.4–0:46.2 |
| 震音 tremolo | 第一、第二小提琴 | 1–4 | 0:00–0:14.4 |
| 震音 | 第一、第二小提琴、中提琴 | 56–57 | 1:50.0–1:53.3 |

### 可选的三轨

## 2_合唱四声部合并_带歌词MIDI

- **`大东北我的家乡_合唱四声部合并_带歌词.mid`**：一个文件、四条轨，依次是 Soprano 女高音、Alto 女低音、Tenor 男高音、Bass 男低音。
  - 每个音符都带歌词（UTF-8），拖腔的音符写 `-`。
  - 速度变化都在文件里，导入时选择导入速度。
- 为什么是四条轨而不是一条：ACE 的一条人声轨只能唱一条旋律。把四个声部压成一条轨，重叠的音会被合并，各声部的歌词也会丢。
  - 如果真的只要一条带歌词的轨，那就只能是主旋律：见 `dadongbei/output/大东北我的家乡_主旋律_带歌词.mid`。
- 导入 ACE Studio：
  1. 放在第 1 小节导入，接受速度信息，得到四条人声轨。
  2. 每条轨加载 Vocal Synth，打开 Choir Mode（2.1.1 以后的版本叫 Unison Mode），加入几位同音区、会唱中文的歌手。先用默认的 offset 和 spread。
  3. 音区：女高 D4–A5（A5 只在副歌 II 和尾声延长处），女低 A3–D5，男高 D3–F♯4，男低 F2–F3。
  4. 播放前确认没有轨被静音或独奏，否则那条轨不会渲染。
- 歌词乱码时：
  - 先换 `…_GBK编码备用.mid`。
  - 再不行就用 `歌词粘贴备用/` 里的文本：每个音符一个字，`-` 是拖腔。双击该段第一个音符，粘贴，回车。
  - `大东北我的家乡_合唱四声部_MusicXML备用.musicxml` 也能导入 ACE，拖腔处画了延长线。
- 多音字：ACE 按不带声调的拼音唱，所以相、乡、唠、嘎、拉、咱都不用管。下面几处导入后点开核对一下：

| 字 | 应读 | 位置（小节） |
|---|---|---|
| 长（土生土长） | zhang | 42、69（第 3 拍，四个声部） |
| 模（模样） | mu | 34、61 |
| 呐（唢呐） | na | 33、60 |
| 血（血肠） | xue，或东北口语 xie | 27 |
| 着（养育着） | zhe | 16（女声） |
| 地（黑土地） | di | 16（女声） |
| 这（这嘎达） | zhe，想要东北味可以改成 zhei | 41、68 |

在 ACE 里改单个音符的拼音，或在 Mac 上用 `acestudio-cli phoneme set`。**最后再改**：重新导入或改歌词会冲掉已改的读音。

## 3_西贝柳斯总谱_好莱坞C调格式

- **`大东北我的家乡_好莱坞总谱_西贝柳斯用.musicxml`**：给西贝柳斯打开的文件。
- **`大东北我的家乡_好莱坞C调总谱_预览.pdf`**：好莱坞 C 调总谱的样子，MuseScore 排版，11×17 英寸，20 页。

**`.sib` 工程只能由西贝柳斯自己存出来。** 它是加密的专有格式，外部没有任何工具能生成。所以这里给的是排好好莱坞格式的 MusicXML，你在西贝柳斯里打开、另存为 .sib 就是工程。

需要 **Sibelius Ultimate**（这份总谱 23 行谱表；Artist 版最多 16 行，First 版最多 4 行），建议 2024.10 或更新的版本（MusicXML 导入改进很多）。

### 已经做好的好莱坞录音棚格式

- 11×17 英寸（Tabloid）竖版，5 毫米谱表。每页一行、4–5 小节，在乐句开头换页。
- 标题栏：cue 号 **1M1**、SCORE IN C、曲名、词曲作者、速度、调性、时长。
- 段落用英文标注（PROLOGUE / INTRO / VERSE / CHORUS 1 / INTERLUDE / CHORUS 2 / CODA），不用字母排练号；技术用语用英文或意大利文。
- 标了 click 提示：click ♩=72 / 128 / 118 / 96、free — fermata、click follows rit.。
- 声部名：Horns 1.3 / Horns 2.4、Trumpet in B♭、Violins I / II、Violas、Celli、Contrabasses。
- 木管、铜管、打击乐、弦乐各组小节线贯通；合唱组不贯通，给歌词留位置。
- 力度记号在乐器谱表下方、人声谱表上方。
- 竖琴有踏板图和踏板变化；定音鼓有调音说明。
- 每个速度变化点都写成了隐藏的速度记号，所以西贝柳斯播放和时间码能跟上渐慢和渐快。
- 谱里是记谱音高加移调信息。这是西贝柳斯导入最稳的写法，A 调单簧管、F 调圆号、降 B 调小号能正确识别成移调乐器。

### 打开后的几步

1. `文件 → 打开` 这个 musicxml。如果问“是否使用文件里的版面”，选是。
2. **看 `主页 → 乐器 → 移调总谱（Transposing Score）` 这个按钮**：让它处于**关闭**状态，总谱就是好莱坞标准的 C 调总谱。短笛、钟琴、低音提琴按惯例仍然是八度记谱。之后分谱会自动按移调乐器出谱。
3. 抽查：
   - 放第 1–4 小节听单簧管、圆号、小号的音高。
   - 看短笛、钟琴、低音提琴的八度对不对。
   - 如果哪行谱的乐器名后面带 “(MusicXML)”，或者不移调：选中那行谱 → `主页 → 乐器 → 更换`，选西贝柳斯自带的 Clarinet in A / Horn in F / Trumpet in B♭，音高不会变。
4. 小节号每小节都标：`外观 → 样式 → 编辑规则 → 小节号 → 每 1 小节`，字号调大。好莱坞常见做法是把小节号放在每小节正中，放在总谱最下方和弦乐上方。
5. 时间码：`播放 → 视频 → 时间码与时长 → 每小节上方`。
6. 如果歌词显示成方块：`文本 → 样式 → 编辑文本样式 → Lyrics`，字体改成 PingFang SC 或宋体。
7. 可选：
   - 圆号改成不带调号：`更换乐器` → Horn in F (no key)。
   - 拍号改成电影谱的大拍号：编辑规则 → 拍号 → 大号 / film score。
8. `文件 → 另存为` .sib。移调总谱的开关状态会跟着工程一起保存。

你也可以用 `文件 → 导入` 把这个 MusicXML 导进现成的好莱坞模板（例如 CineScore、Scoring Express），版面会直接套用模板的样式。
