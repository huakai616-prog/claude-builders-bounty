# 我不难过（副歌）· 人声与弦乐四重奏

原曲：杨明学 词，李偲菘 曲，孙燕姿 演唱。
按要求保留**原调 ♭E 大调（1=♭E）**，4/4，♩=68。
编制：人声 + Violin I / Violin II / Viola / Violoncello（弦乐四重奏）。
风格：流行综艺编曲，抒情起、高燃收。副歌唱一遍，带前奏和尾奏。
改编、制谱：花开当富贵。

**下载**：打开编曲交付中心 https://claude.ai/artifact/He3NTJ1vbPydtB8fRJJjsN ，在「我不难过」那一栏点「下载到电脑」。

## 结构

| 段落 | 小节 | 内容 |
|---|---|---|
| 前奏 Intro | 1–4 | A♭maj9 长音铺底；第一小提琴在高八度唱出「你爱过，别太伤痛，我不难过，这不算什么」的钩子；第 4 小节停在 B♭7sus4，人声弱起「我」 |
| 副歌 A（抒情），排练号 A | 5–8 | 我真的懂你不是喜新厌旧，是我没有陪在你身边，当你寂寞时候 |
| 副歌 A（推进） | 9–12 | 别再看着我说着你爱过……我也不懂。第 11 小节起中提琴改十六分音符，两把小提琴六度、三度双线。**第 12 小节第 4 拍弦乐全停**，人声清唱「懂就」 |
| 副歌 B（高燃），排练号 B | 13–20 | 「让我走」弦乐全奏落拍进入，一直推到「最后的宽容」。「宽容」走 **C♭ → D♭ → E♭（♭VI – ♭VII – I）**，渐宽 |
| 尾奏 Coda，排练号 C | 21–23 | 人声收住后，第一小提琴弱奏回声「我不难过」，A♭maj9 → A♭m6 → E♭(add9) 结束，渐慢 |

## 编配思路

- **和声简单而高级**：骨架是流行歌最常见的 IV – V – iii – vi（A♭ – B♭ – Gm – Cm），高级感来自色彩音和借用和弦：
  - 大量 add9 / maj9：A♭maj9、Fm9、Cm9、D♭maj9。
  - 「别再看着我」「我并不懦弱」旋律里本来就有 ♭6（C♭），这里配借用的小四级 **A♭m(add9) → A♭m6**，第二次换成 **D♭9**（♭VII9），直接落回 E♭/G。
  - 「这会是我最后的宽容」：B♭sus4 不解决到主和弦，而是上行半音到 **C♭maj7（♭VI）**，再到 **D♭（♭VII）**，第 21 小节才落到 E♭。人声的「容」（E♭）横跨这三个和弦，大提琴低音 B♭ → C♭ → D♭ → E♭ 一路上行。这是和泪海结尾同一个「燃点进行」。
  - 结尾 A♭maj9 → A♭m6 → E♭(add9)：中提琴 C → C♭ → B♭ 半音下行，第一小提琴 F → E♭。
- **层层加码（综艺高燃的核心）**：

  | 段落 | 大提琴 | 中提琴 | 第二小提琴 | 第一小提琴 |
  |---|---|---|---|---|
  | 前奏 | 全音符、二分音符 | 长音 | 长音 | 钩子旋律 |
  | A 前半（5–8） | 二分音符下行低音 | 八分音符分解和弦（波浪，“come onde”） | 长音光环 | 只在人声长音「旧」「候」处回声 |
  | A 后半（9–12） | 二分音符；第 12 小节十六分音符八度交替 | 第 11 小节起十六分音符，第 12 小节十六分音符重复音 | 与第一小提琴六度、三度双线，第 12 小节三度上行音阶 | 高音区对位旋律 |
  | B 前半（13–16） | 八分音符八度跳进 | 十六分音符波浪 | 八分音符重复音（marcato） | 高音区对位旋律（C6–F6） |
  | B 后半（17–20） | 同上，第 20 小节双音 | 同上 | 十六分音符，3+3+2 重音 | 最高到 A♭6，第 20–21 小节 E♭6 → F6 → G6 跟着 ♭VI – ♭VII – I 上行 |

- **呼应**：人声在唱字时弦乐多是长音，第一小提琴只在人声的长音和气口里动（「旧」「候」「过」「走」「活」）。
- **清唱留白**：第 12 小节弦乐在第 4 拍全部停下，只剩人声清唱「懂就」，下一拍全奏砸进「让我走」。
- 各声部都在舒适音区：第一小提琴最高 A♭6，大提琴最低 C2（空弦），中提琴最低 C3。人声 B3（「看」「不」的低 C♭）到 C5。
- 这首旋律常在 E♭–D、A♭–G 之间级进，所以弦乐在人声唱 D、G 的地方不放高于它的 E♭、A♭，避免小九度。脚本会自动检查：每个十六分音符的纵向音程（包括和人声之间）没有小二度或小九度冲突；任意两个声部之间，包括和人声之间，都没有平行五度和平行八度。

## 转写说明

旋律按简谱逐小节转写，每小节 4 拍，副歌从 𝄋「我真的懂」到「最后的宽容」（原谱第 9–24 小节）。

- 歌词用第一遍（「就让我走……最后的宽容」）。
- 结尾「宽容」用原谱第三房的写法（`0 5̣ | 1 2 1 1 -`），在 4/4 里拖长，横跨 ♭VI – ♭VII – I。
- 谱上这几处是**低八度**，照谱写了：「陪」「你（的影子）」（C4）、「寞」「我（生活）」（C4）、「看」「不（懦弱）」（C♭4，也就是 B3）、「难」「什」（C4）。前三组都是在高音之间突然掉下一个八度、下一个音又跳回来（例如「寂寞时」A♭4 → C4 → B♭4）。如果你记得原唱这里没有往下掉，告诉我，每处改一个 token 就行。

## 在西贝柳斯里打开

西贝柳斯的 `.sib` 工程只能在西贝柳斯里存出来，这里给的是 MusicXML，是西贝柳斯官方支持的导入格式。

1. `文件 → 打开`，选 `我不难过_副歌_人声弦乐四重奏.musicxml`（或者直接拖进西贝柳斯）。
2. 导入对话框如果有版面相关的选项，选保留文件里的版面。各声部已经带了乐器音色 ID（strings.violin / strings.viola / strings.cello），会自动对应到正确的乐器。
3. 打开后 `文件 → 另存为`，就得到 `.sib` 工程。
4. 版面：11×17 英寸竖版（好莱坞总谱纸），7.2 毫米谱表，每小节有小节号。前奏一行 4 小节，第 5–10 小节一行 3 小节，十六分音符密集的第 11–20 小节一行 2 小节，尾奏一行 3 小节。首页标题栏：左边作词、原唱，右边作曲、改编、制谱。如果想让西贝柳斯自己排，全选后执行 `版面 → 格式 → 解锁格式`，再执行 `外观 → 重置设计 / 重置位置`。
5. 想在西贝柳斯里也加封面：`创建 → 标题页`。PDF 里的封面可以直接参照。

## 在 ACE Studio 里呈现

1. 导入 `我不难过_副歌_人声弦乐四重奏_全轨.mid`，保留速度信息（第 19 小节起渐宽，结尾渐慢）。
2. 人声轨：加载 **Vocal Synth**，选一个中文流行女声（中音区、干净一点的唱法更接近原唱）。歌词已经在音符上，拖腔音符标的是 `-`，会连着上一个字唱。如果歌词是乱码，删掉这一轨，改导 `我不难过_人声_带歌词_GBK编码备用.mid`。也可以单独把 `我不难过_人声_带歌词.mid` 拖进一条人声轨。
3. 四个弦乐轨：都加载 AI 乐器 **String Section**，speaker 分别选 **Violins I / Violins II / Violas / Celli**。演奏法保持默认的智能模式（smart mode）即可，这版没有拨弦，也没有弱音器。
4. 第 12 小节第 4 拍弦乐是故意空着的（人声清唱），不要补。
5. 弦乐的 AI 渲染在播放时进行，被静音或独奏的轨不会渲染；弦乐听起来是钢琴声，说明那条轨还没加载音源。

## 修改后重新生成

```bash
pip install music21 mido pypdf cffi
python3 build.py --check  # 只检查音域、声部冲突和平行五八度
python3 build.py --pdf    # 生成全部文件到 output/，包括好莱坞总谱 PDF
```

乐谱数据都写在 `build.py` 里，每小节一行，时值以十六分音符为单位。改一处，MusicXML、MIDI、字幕和 PDF 会一起更新。
封面、标题栏、页眉页脚的文字在 `build.py` 的 `META` 里；版式在仓库的 `tools/hollywood/`（所有歌共用，见 `.claude/skills/hollywood-score/SKILL.md`）。PDF 需要 MuseScore 4（没有会自动下载）和 Chromium。
