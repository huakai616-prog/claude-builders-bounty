# 诀别书 钢琴原谱转写

原谱是用户发的三张钢琴谱截图（作曲 邓垚，制谱 张科桔），共 52 小节，一个降号，4/4，♩=112。截图本身不进仓库，理由有两个：一是别人制的谱，二是仓库公开。

## 文件

| 文件 | 用途 |
|---|---|
| `piano.json` | 最终转写，一小节一个对象，`build.py` 的旋律和低音核对都以它为准 |
| `钢琴原谱_转写校对.pdf` | 用 LilyPond 把转写重新排成钢琴谱，换行和原谱一致，方便逐行对照 |
| `钢琴原谱_转写.mid` | 转写的试听 MIDI：实际音高（已按 8va 升八度），♩=112 |
| `merge.py` | 把 `work/c*_final.json` 合并成 `piano.json`，并重新生成上面两份校对文件 |
| `work/` | 过程稿：每段两份独立转写（`_t1`、`_t2`），以及核对后的定稿（`_final`） |

## 格式

每小节写成 `{"bar", "rh", "lh", "lh_clef", "rh_ottava", "rh_ottava_until", "marks", "harmony", "doubts"}`。

- `rh`、`lh`：右手、左手，每个声部一个字符串，语法和 `build.py` 相同（时值以十六分音符为单位）。
- 音高按谱面写（B 一律写 B♭）。8va 小节写的是**印刷音高**，实际音高要高一个八度。
- 8va 如果在小节中途结束，就写 `rh_ottava_until`，值是结束处的十六分音符位置。

## 怎么做的

52 小节分成 8 段，流程如下：

1. 每段由两个代理各自独立转写。每小节都有标好音名刻度线的 4 倍放大图可以对照。
2. 第三个代理逐条比对两份结果的差异，回到原图裁决，再用 LilyPond 把结果画回五线谱，和原图逐小节对照。
3. 第四个代理专门挑错。

结果：两份独立转写的音高和节奏完全一致，挑错环节也没有发现差异。只剩和弦标记的写法有出入，这属于分析上的取舍，不影响音符。

## 值得注意的地方

- 8va：第 27 小节到第 31 小节第 3 拍、第 37–40 小节、第 49–52 小节。
- 第 18、26 小节：右手是 B♭–D♭–F–A / G，叠在 C7 分解和弦上，形成 C7(♭9,13) 的色彩。
- 第 22 小节：C6 前面印了还原号，是 A7(♯9) 的 ♯9。
- 第 49–52 小节：左手换成高音谱号。结尾停在 C/B♭（B♭ 上叠 C–E–G），旋律停在 C7，是一个不解决的开放结尾。
