# 我和我的祖国（全曲）· 四声部独唱与弦乐四重奏

原曲：张藜 词，秦咏诚 曲，李谷一 首唱。旋律与歌词依据用户给的 1=♭E 声乐钢琴谱（范哲明 配伴奏版）转写。
改编、制谱：花开当富贵。

- **调与拍子**：按原谱 **1=♭E（♭E 大调）**，6/8，副歌里的「祖国」「心窝」两小节是 9/8，照原谱。
- **速度**：Moderato，附点四分音符 = 56，全长约 2 分 51 秒。
- **编制**：女高音、女低音、男高音、男低音**各一位歌手**（单人合唱，不是合唱团），加第一小提琴、第二小提琴、中提琴、大提琴。
- **结构**：原谱的反复记号全部展开写，共 73 小节。
  - 前奏 → 主歌一 → 副歌一 → 间奏 → 主歌二 → 副歌二 → 啦啦段 → 尾声。
  - 第二遍没有照抄第一遍，配法都重新写过。

## 转写说明

- 原谱 1=♭E，中音区的 1 记作 ♭E4。旋律音区 ♭B3–G5，照原谱，没有移八度。
- 第二段歌词和第一段的音符对法有三处不同，都照原谱处理：
  - 「每**当**大海在微笑」：「当」唱两个音（6 5）。
  - 「分享**海的**欢乐」：「海的」两个字挤在同一个 5̣ 下，这里拆成两个八分音符。
  - 「**你**是**大**海」：「你」「大」各唱两个音。
- 「**母亲**的脉搏」：「母亲」两个字都在第一个音 7̣ 下，拆成两个十六分音符；「的」在 6̣ 上。
- 「心**中**的歌」的 2̇（F5）有延长记号，最后的「歌」也有延长。
- 原谱第一遍结尾是一房「和我诉说」（1. 1 0），然后反复回到前奏；第二遍走二房「心中的歌」，接啦啦段和尾声。这版照这个顺序全部展开写。
- 由三位独立的核对者分别转写后比对：旋律和节奏逐小节一致。唯一有分歧的是「母亲的脉搏」几个字的位置，两位核对者和放大后的原图都是「母亲」同在第一个音上，照此处理。
