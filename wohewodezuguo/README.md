# 我和我的祖国（全曲）· 四声部独唱与弦乐四重奏

原曲：张藜 词，秦咏诚 曲，李谷一 首唱。旋律与歌词依据用户给的 1=♭E 声乐钢琴谱（范哲明 配伴奏版）转写。
改编、制谱：花开当富贵。

- **调与拍子**：按原谱 **1=♭E（♭E 大调）**，6/8，副歌里的「祖国」「心窝」两小节是 9/8，照原谱。
- **速度**：Moderato，附点四分音符 = 56，全长约 2 分 51 秒。
- **编制**：女高音、女低音、男高音、男低音**各一位歌手**（单人合唱，不是合唱团），加第一小提琴、第二小提琴、中提琴、大提琴。
- **结构**：原谱的反复记号全部展开写，共 73 小节。
  - 前奏 → 主歌一 → 副歌一 → 间奏 → 主歌二 → 副歌二 → 啦啦段 → 尾声。
  - 第二遍没有照抄第一遍，配法都重新写过。

## 转写说明

- 原谱 1=♭E，中音区的 1 记作 ♭E4。旋律音区 ♭B3–G5，照原谱，没有移八度。
- 第二段歌词和第一段的音符对法有三处不同，都照原谱处理：
  - 「每**当**大海在微笑」：「当」唱两个音（6 5）。
  - 「分享**海的**欢乐」：「海的」两个字挤在同一个 5̣ 下，这里拆成两个八分音符。
  - 「**你**是**大**海」：「你」「大」各唱两个音。
- 「**母亲**的脉搏」：「母亲」两个字都在第一个音 7̣ 下，拆成两个十六分音符；「的」在 6̣ 上。
- 「心**中**的歌」的 2̇（F5）有延长记号，最后的「歌」也有延长。
- **歌词**：第 54 小节原谱印的是「浪的忧愁」，通行歌词是「我分担着**海**的忧愁，分享**海**的欢乐」（浪花分担大海的忧愁和欢乐，前后两个「海」对仗），「浪」是印刷错误，这版唱「海的忧愁」。
  原谱另有两处和常见版本不同，照原谱没改：第 27 小节「紧**贴**着」（常见的是「紧**依**着」），第 11–12 小节「分**隔**」（常见的是「分**割**」，读音一样）。要改告诉我。
- 原谱第一遍结尾是一房「和我诉说」（1. 1 0），然后反复回到前奏；第二遍走二房「心中的歌」，接啦啦段和尾声。这版照这个顺序全部展开写。
- 由三位独立的核对者分别转写后比对：旋律和节奏逐小节一致。唯一有分歧的是「母亲的脉搏」几个字的位置，两位核对者和放大后的原图都是「母亲」同在第一个音上，照此处理。

## 编配思路

- **四个声部各一人，旋律跟着歌词走**：这首歌第二段写的是浪花和大海，所以让女声唱浪花、男声唱大海，「海是那浪的依托」交给最低的男低音。第一段主歌交给女低音：旋律 ♭B3–F5 正好是她的音区，又把女高音的声音留到副歌才第一次出现。
- **和声简单而高级**：
  - 骨架是 I–IV–V。主歌里 A♭–A–B♭ 的半音低音（IV → F/A → V）照原谱的走法。
  - 「我歌唱每一座高山」的低音一路往上爬（C–F–A♭–B♭–♭E–G–A♭），唱山就往上走。
  - 副歌后半用 iii–vi–II7–V–I 五度圈进行。
  - 色彩来自 A♭maj7 / maj9、B♭7sus4、G7/B、F/A 这些副属和挂留和弦。
  - 尾声「心」用 A♭/B♭，让「中」的属七和弦七音事先有准备，再落到 ♭E。
- **弦乐的点子都从这首歌来**：
  - 前奏、主歌一的拨弦，模仿原曲里竖琴一样的琶音。
  - 间奏和副歌二的十六分音符琶音，取自原谱钢琴左手的上下大琶音。
  - 第 32、64 小节小提琴三度上行，是原谱一房、二房钢琴的过门。
  - 结尾的二对三律动也来自原谱最后一小节。
- **和以前几首的不同**（泪海、茶汤、我不难过）：
  - 前奏不是「长音铺底 + 第一小提琴唱钩子」，是中提琴唱主题、拨弦伴奏。
  - 不再用「中提琴八分音符波浪分解和弦」铺底：主歌二原来整段写了类似的中提琴反拍，审稿时发现和以前太像，41–48 小节删掉了，改成大提琴独自摇船加男声哼鸣；只在 49–51 小节女低音唱旋律时留了三小节很轻的中提琴反拍（dolce）。
  - 没有「高潮前一拍弦乐全停」。这首的留白是主歌中间两小节的清唱（袅袅炊烟），不是在高潮前。
  - 没有 ♭VI–♭VII–I、借用小四级、1–7–6–5 下行低音、maj9 → m6 → I 的结尾。
  - 编制本身不同：四位独唱，人声之间有对唱、哼鸣、分部。
- 第 57–60、65–73 小节第一小提琴加了 8va 记号，只改显示，MIDI 和 MusicXML 里都是实际音高。
- 以前没用过的手法：拨弦竖琴、心跳拨弦、清唱段、接力上行（琶音从大提琴传到中提琴再传到第二小提琴）、「漩涡」打旋、男声划船节奏。

## 在西贝柳斯和 ACE Studio 里

步骤写在 `output/使用说明.md`（它也在交付中心下载的压缩包里）。要点：

- 西贝柳斯：`文件 → 打开` MusicXML，另存为 .sib。8 行谱，Sibelius Artist 及以上。
- ACE Studio：导入全轨 MIDI，四条人声轨**各选一位歌手、不开 Choir 模式**；弦乐加载 String Section。
  - 拨弦位置照说明里的表手动设。
  - 最后的「歌」要画音量渐弱。

## 修改后重新生成

```bash
pip install music21 mido pypdf cffi
python3 build.py --check   # 音域、歌词、小二度/小九度冲突、平行五八度、人声交叉；必须什么都不输出
python3 build.py --pdf --mp3   # MusicXML、MIDI、字幕、歌词文本、好莱坞总谱 PDF、试听 mp3
```

- 乐谱数据都在 `build.py`：每个声部一个 dict，每小节一个字符串，时值以十六分音符为单位（6/8 一小节 = 12，9/8 = 18）。
- `engine.py` 管混合拍子的记谱切分、四个人声声部、br 气口、拨弦/拉弦和延长记号。
- PDF 需要 MuseScore 4 和 Chromium，环境准备见 `.claude/skills/hollywood-score/SKILL.md`。
