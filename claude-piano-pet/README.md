# 小 Claude 弹钢琴

一段 5 秒无缝循环的 JavaScript 动画：橙色的 Claude 小宠物站在钢琴后面弹 C–Am–F–G，
琴键按下时会亮起，音符从琴键上飘起来，旁边的节拍器跟着 96 BPM 摆动。

## 运行

直接用浏览器打开 `index.html` 即可，不需要构建，也没有任何依赖。

- 点击画面或「暂停」按钮：定格 / 继续
- 「开启声音」：用 Web Audio 实时合成和动画同步的旋律（浏览器要求点击后才能出声）
- 页面跟随系统的深色 / 浅色模式：白天是蓝天白云，夜里是月亮和星星

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构、样式和场景配色（CSS 变量） |
| `piano-pet.js` | Canvas 2D 动画、乐谱、手部动作和声音合成 |

## 循环是怎么做到无缝的

乐谱是 96 BPM、4/4 拍，2 小节 = 8 拍 = 5 秒。每一帧只由循环时间 `t = 时间 mod 5` 计算：

- 琴键的按下和发光用 `since(t, 音符时间)` 算，跨过循环边界也连续
- 身体的弹跳、左右摇摆、节拍器摆锤的周期都能整除 5 秒（0.625 秒、1.25 秒、2.5 秒）
- 手在两个音之间沿弧线移动，最后一个音会接回第一个音

所以第 5 秒和第 0 秒的画面完全一致。
