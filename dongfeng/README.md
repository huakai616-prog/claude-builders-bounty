# 冬风（肖邦 练习曲 Op. 25 No. 11）· 弦乐四重奏

原曲：肖邦（F. Chopin）钢琴练习曲 Op. 25 No. 11《冬风》，a 小调。改编、制谱：花开当富贵。
全曲 96 小节，**a 小调（原调）**，2/2 拍：Lento（♩=60）4 小节引子，然后 Allegro con brio 𝅗𝅥=69（肖邦原速）。
编制：Violin I / Violin II / Viola / Violoncello。全长约 3 分钟。纯器乐，没有人声。

> 调：没有指定调，按原调 a 小调。弦乐的空弦 A、E、D 正好是主和弦、属和弦和下属和弦的音，结尾 fff 的和弦最响亮。

## 转写与核对

- 你给的 PDF（虫虫钢琴版，17 页）是五线谱，不需要从简谱转写。音符数据先取自另一份公开的机读乐谱，再派 17 个检查员按页逐音和你的 PDF 对照，每个差异由另一个检查员放大复核。
- **音符只有一处不同**：第 20 小节第 3 拍，你的谱是 C#6 A5 D6 F5 G#5 F5，另一版本是 D#6 A5 C6 F5 G#5 F5。这里**按你的谱**写。
- 你的谱第 44–45 小节有一处印刷错误：第 45 小节右手前两拍的 8va 线，被印到了第 44 小节左手下面。按正确读法处理（第 45 小节右手前两拍高八度，左手不变）。
- 力度按你的谱。另一版本多出的「f risoluto」「dim.」「marcato」「marcatissimo」等都没有用。四重奏在三处从 p 跳到 f，另加了渐强（第 66–68、82、86 小节），其他版本这几处本来就印着 cresc.。

## 编配思路

肖邦的右手是「风」：每小节 24 个六连音十六分音符，𝅗𝅥=69 时每秒 13.8 个音，一直吹到结尾；左手是一支进行曲式的主题（E E. E ｜ E F ｜ E C E，和引子一样）。钢琴一只手能从最高音区一路扫到低音区，一件弦乐器不行，所以：

- **风在四件乐器之间接力。** 每一阵「落下的风」（第 5–8、13–16、23–26、31–34、69–72、77–80、89–92 小节）按小节往下传：第一小提琴 → 第二小提琴 → 中提琴 → 大提琴，一小节低一个八度，和钢琴一样从高处扫到低处。风往上吹的地方（第 19、37、59–60、81 小节）接力反过来走。每件乐器一次只拉一两小节，有喘气的地方；在舞台上，风从左边吹到右边。
- **主题交给当时空着的乐器。** 第 5 小节主题在中提琴（A 弦上的 E4），大提琴用空五度托底，第二小提琴拉中声部；风传到中提琴时，主题交给大提琴（第 7 小节，正好是肖邦左手低八度的地方）。第 13 小节再现时主题用八度（第二小提琴 E5 + 中提琴 E4）加厚。
- **只动八度，不改音。** 所有音型都是肖邦的原音，程序直接从钢琴谱数据里取，只改八度和声部。肖邦写 8va 的地方（第 5、13、23、69、77 小节，最高 F7）整体移低一个八度，第一小提琴最高到 E7 左右。
- **展开部（第 41–44 小节）**：肖邦把主题放到右手和弦、风放到左手。四重奏照做：两把小提琴拉主题和弦，风在中提琴和大提琴里往下吹。
- **第 45–48 小节**：降 A 大调的主题放在中提琴的次中音区（fp），第一、第二小提琴轮流拉风。
- **第 49–56 小节**：肖邦左手的八度低音主题，由中提琴和大提琴八度齐奏。
- **高潮（第 61–64 小节，ff）**：两只手反向运动。两把小提琴八度齐奏往下，中提琴和大提琴八度齐奏往上，在减七和弦上相遇（fz）。
- **第 65–68 小节**：F D E G# 的低语（p），渐强、渐慢，中提琴和大提琴的半音下行加进来，推回 a tempo 的再现部。
- **结尾**：第 89–92 小节风最后一次从第一小提琴落到大提琴，两把小提琴在高两个八度上拉肖邦左手的半音下行（ff）；第 93–94 小节 fff 全奏和弦，用上 A、E、D 空弦；第 95 小节大提琴、中提琴先起，两把小提琴用三十二分音符接上去，四个八度的音阶冲到最后的 A。
- **引子（Lento）**：前两小节主题由大提琴独奏（A 弦高把位，p espressivo），第 3–4 小节四重奏 pp 奏肖邦自己的四声部和弦。

### 为了音域改动的几个音

弦乐音域装不下钢琴的地方，只把个别音移一个八度，其余不动：

| 小节 | 声部 | 改动 |
|---|---|---|
| 7、25 | 中提琴 | 风的最后一个音（A2 / G2）移高一个八度，中提琴最低只到 C3 |
| 9、29、35、36、51、58 | 小提琴 | 风的最后一个低音（F3 / F#3）移高一个八度，小提琴最低只到 G3 |
| 26、63 | 大提琴 / 中提琴 | 低于 C2 的 B1 改成 B2（中提琴改 B3） |
| 41 | 中提琴 | 最后一个音 Bb2 改成 C#3（同一个和弦里的音） |
| 51、68 | 小提琴 | 冲到 F7 的顶点折回一个八度（第 51 小节第二小提琴升到 Gb6，第一小提琴从下一拍接着往下；第 68 小节后两拍移低八度，正好接上第 69 小节的开头） |
| 28 | 第二小提琴 | 内声部 D C B 的附点三连音节奏改成平均三连音，好读好拉 |
| 95 | 全体 | 结尾音阶按乐器重新分配（大提琴、中提琴、两把小提琴接力） |

## 在西贝柳斯里打开

西贝柳斯的 `.sib` 工程只能在西贝柳斯里存出来，这里给的是 MusicXML，是西贝柳斯官方支持的导入格式。

1. `文件 → 打开`，选 `冬风_弦乐四重奏.musicxml`（或者直接拖进西贝柳斯）。
2. 导入对话框如果有版面相关的选项，选保留文件里的版面。各声部已经带了乐器音色 ID（strings.violin / strings.viola / strings.cello）。
3. 打开后 `文件 → 另存为`，就得到 `.sib` 工程。分谱在「窗口 → 分谱」里，西贝柳斯自动生成。
4. 版面：11×17 英寸竖版，每行两小节、每页四行，段落开头都在行首。想让西贝柳斯自己排，全选后执行 `版面 → 格式 → 解锁格式`。

## 在 ACE Studio 里呈现

1. 导入 `冬风_弦乐四重奏_全轨.mid`，保留速度信息（引子 ♩=60 和两个延长记号，第 68 小节渐慢）。
2. 四条轨都加载 AI 乐器 **String Section**，speaker 分别选 **Violins I / Violins II / Violas / Celli**。演奏法保持智能模式。
3. 六连音很快（每秒 13.8 个音）。如果 AI 弦乐在快速音型上发糊，可以先把工程速度降到 𝅗𝅥=60 左右听效果。
4. 确认没有轨被静音或独奏，从头播放一遍，让所有轨都渲染。

## 总谱 PDF 的版式

用仓库里的好莱坞模板 `tools/hollywood` 排（MuseScore 4 排谱，Chromium 画封面和页眉页脚）：

- **封面**：双线边框；「FULL SCORE / Score in C · Concert Pitch」；大字标题「冬风」和 WINTER WIND；中英文副标题；署名表（作曲 肖邦、原作 钢琴练习曲 Op. 25 No. 11、改编 花开当富贵、制谱 花开当富贵）；调 · 速度 · 时长；编制；页脚「花开当富贵」。
- **首页标题栏**：标题、副标题居中；左下原作；右下作曲、改编、制谱。
- **每页**：页眉「冬风 · 练习曲 Op. 25 No. 11 FULL SCORE IN C」和大号页码；页脚「改编 · 制谱 花开当富贵」和「PAGE n OF 12」。
- **排版**：每行两小节，每页四行（第 9 页的第 67–68 小节四件乐器都是六连音，太高，那页排三行）。排练号 A–J 都在行首，带段落名。六连音的「6」只在一段音型开始时标一次。第一小提琴整小节在谱表上方的地方加了 8va 线（只改显示，MIDI 和 MusicXML 里是实际音高）。

## 修改后重新生成

```bash
pip install music21 mido pypdf cffi
python3 dongfeng/build.py --check  # 检查音域、双音能不能按、纵向小二度/小九度、平行五八度，必须什么都不输出
python3 dongfeng/build.py --pdf    # 生成 MusicXML、MIDI 和好莱坞总谱 PDF
```

- 音乐数据都在 `build.py`：`RH` / `LH` 是肖邦的原音型（实际音高，每小节 24 个六连音），`arrange()` 里一小节一行，写四个声部。时值以「tick」为单位，一小节 48 个：2 = 六连音十六分，3 = 十六分，4 = 三连音八分，12 = 四分。语法见 `engine.py` 开头。
- `engine.py` 是这首新加的通用引擎（解析、MusicXML、MIDI、检查），以后改编钢琴曲可以直接复制。
- PDF 需要 MuseScore 4 和 Chromium，环境准备见 `.claude/skills/hollywood-score/SKILL.md`。试听 mp3 用 FluidSynth 另外渲染：
