## 编配思路

- **「风」是主角**：肖邦右手的六连音就是冬风。钢琴一只手能扫四个八度（第 5–8 小节从 F7 落到 F3），任何一把弦乐器都做不到，所以把它按小节在四件乐器之间传递：一小节一件乐器，每一件都接着肖邦的线往下走，听起来是一整股风从最高处刮到最低处。强奏再现时（13、31、69、77 小节）改成两件乐器八度成对下滑，风更厚。
- **往上的时候反过来**：27–28、37、85–86 小节肖邦的音型从低往上走，就从中提琴、大提琴往上交给小提琴。
- **进行曲主题**（肖邦左手的和弦，E. E E F | E C E）交给当时没在奏「风」的乐器，用双音、三音和弦撑起来：大提琴大多在 fz 的根音上起、再接主题；中提琴和第二小提琴用六度、五度双音。41–44 小节主题交给两把小提琴，风交给低音弦。
- **弦乐的实际音域**：第一小提琴快速音型最高到 D7，只有少数单个的顶点到 E7（第 12、76 小节）；肖邦写了 8va 的地方大多降一个八度。中提琴快速音型到 A5，大提琴快速音型到 A4。
- **双音都按空弦和把位检查过**（`build.py --check`）：两个音必须在相邻两根弦上，手指跨度在一个把位之内；快速音型里超过十六个半音的大跳（要跳过整根弦）都换了八度或换了乐器。
- **音色**：引子 sul G、sul tasto、无揉弦；风眼 sul ponticello；震音在 59–60 小节（大提琴）、62 和 64 小节（中提琴、大提琴）、66–68 小节（风眼的持续音）；53–54 小节和弦扫弦；81–84 小节第一小提琴跳弓；结尾 A 空弦共鸣（大提琴、中提琴的最后一个和弦都含 A 空弦）。
- **8va**：第一小提琴只在真正高的地方（一拍里碰到 B6，或连续三个音在 G6 以上）加 8va 线，读谱时少数加线；MusicXML 里是实际音高，MIDI 不受影响。
- **和声对照**：`build.py --harm` 逐拍对照肖邦原作的低音和和声。剩下的差异都是有意的：大提琴在奏「风」的那几小节（8、16、26、33、72）没有肖邦用踏板延长的最低音，和声由音型自己带出；41–44、59–60、66–68、85–87 小节加了持续低音（A、C、E、F）；第 95 小节音阶的写法不同（见下）。
- **审稿**：编配经过演奏员、编配、和声三个视角的审稿，改了一轮：去掉了几处和第一小提琴抢位置的重复声部、D 段改成两把小提琴轮流接风、尾声加了跳弓，第 92 小节大提琴加入半音下行。

## 转写说明

用户给的是 17 页钢琴谱（虫虫音乐版，潘小生制谱）。底稿用公开的 ASAP 数据集（Paderewski 版文本的 MusicXML），再由多个代理把用户 PDF 的每一页、每个音和底稿逐一核对、独立复核。结果写在 `chopin.py`：

- 全曲 96 小节只有两处和底稿不同：
  - **第 20 小节第 3 拍**按你的谱是 C♯6 A5 D6 F5 G♯5 F5（底稿把第 1 拍的音抄错了）；
  - **第 16 小节第 4 拍第一个音**两份谱都没写还原号（按规则会是 D♭4），这里按半音阶上行 B–C–C♯ | D–D♯–E 写成 **D 还原**。如果你的版本明确是 D♭，告诉我。
- 力度和表情用肖邦原版（Paderewski）的标记：第 5 小节 f risoluto、第 7 小节 dim.、第 9 小节 marcato、第 45 小节 fp、第 92 小节 marcatissimo、第 93 小节 fff 等。你的谱上有些没印，这些是原作的。

## 请你确认

- 调：保留原调 **a 小调**（对弦乐最合适，A、E、D、G 空弦都能共鸣）。要换调告诉我。
- 速度：按肖邦的 𝅗𝅥 = 69。弦乐四重奏演奏这首非常吃力，如果要给真人乐手演，可以放慢到 𝅗𝅥 = 60–63，改 `TEMPO_MARKS` 和 `TEMPI` 一处就行。
- 结尾第 95 小节：肖邦是双手八度的 a 旋律小调音阶（4 个八度，28 个音）。这里改成四件乐器同时从各自的 C 起（中提琴、大提琴是 C 空弦），一人一条两个八度的音阶、一个弓子拉完，合起来仍是四个八度，落到最后的 A 和弦上（第一小提琴 A6，第二小提琴 E5 + A5，中提琴 A3 + E4 + A4，大提琴 A2 + E3 + A3）。

## 在西贝柳斯里打开

1. `文件 → 打开`，选 `冬风_弦乐四重奏.musicxml`（或者直接拖进西贝柳斯）。
2. 导入对话框有版面选项时，选保留文件里的版面。四个声部带了乐器 ID（strings.violin / strings.viola / strings.cello），会自动对应到正确的乐器。
3. 打开后 `文件 → 另存为`，就得到 `.sib` 工程。
4. 版面：11×17 英寸竖版，引子一行 4 小节，Allegro 之后一行 2 小节，最后一行 93–96 四小节。六连音只在每一段开头标「6」，后面省略（西贝柳斯里如果「6」全显示出来，全选后在「属性 → 连音」里改成不显示）。
5. 分谱：西贝柳斯会自动生成分谱；PDF 分谱已经做好，在 `冬风_分谱.pdf`。

## 在 ACE Studio 里呈现

1. 在第 1 小节导入 `冬风_弦乐四重奏_全轨.mid`，**保留速度信息**（引子 ♩=52 和延长，第 5 小节起 𝅗𝅥=69，第 68 小节渐慢，第 69 小节回原速，结尾放宽）。
2. 四条轨都加载 AI 乐器 **String Section**，speaker 分别选 **Violins I / Violins II / Violas / Celli**（这是四重奏，想要更「独奏」的声音可以选单把小提琴 / 中提琴 / 大提琴的 speaker）。
3. 演奏法保持智能模式。谱上的 sul tasto、sul ponticello、震音在 MIDI 里分别是长音和重复的三十二分音符，需要的话在 ACE 里给这几段手动选对应的演奏法：引子（1–4）sul tasto，风眼（65–68）sul ponticello，59–60 小节大提琴、62/64 小节中提琴和大提琴、66–68 小节是震音，81–84 小节第一小提琴是跳弓（spiccato / sautillé）。MIDI 的小节和总谱一一对应（没有弱起，ACE 第 N 小节 = 总谱第 N 小节）。
4. 第 62、64 小节和弦后面的半小节休止是故意的，不要补。
5. 确认没有轨被静音或独奏，从头播放一遍让所有轨都渲染。

## 修改后重新生成

```bash
pip install music21 mido pypdf cffi
python3 dongfeng/build.py --check    # 音域、双音、快速大跳检查，干净时什么都不输出
python3 dongfeng/build.py --harm     # 逐拍和肖邦原作对照低音与和声（给人看）
python3 dongfeng/build.py --dump /tmp/bars.txt   # 每小节的肖邦原文和四个声部，文字版，方便审稿
python3 dongfeng/build.py --pdf --parts --mp3   # 全部文件
```

- 乐谱数据都在 `build.py`：每个声部一个 dict，每小节一个字符串；时值以 1/24 拍为单位（四分音符 = 24，六连音十六分 = 4，三连音八分 = 8，十六分 = 6）。`W(小节, 起拍, 止拍, sh=八度)` 从 `chopin.py` 取肖邦右手的音型，`L()` 取左手。改一处，MusicXML、MIDI、总谱、分谱会一起更新。
- `engine.py` 是通用引擎（MusicXML 写出、六连音 / 三连音、双声部、谱号、8va、弓法、震音、双音可演奏性检查、MIDI），以后改编别的钢琴曲可以直接复用。
- 封面、标题栏、页眉页脚在 `build.py` 的 `META`；版式在仓库的 `tools/hollywood/`（总谱 `hollywood.mss`，分谱 `hollywood_part.mss`）。PDF 需要 MuseScore 4（没有会自动下载）和 Chromium；mp3 需要 fluidsynth、fluid-soundfont-gm 和 ffmpeg。
